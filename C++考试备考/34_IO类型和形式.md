## 题目 / Вопрос

- **中文**：C++ 程序可以使用哪些类型和形式的输入/输出？  
- **俄文**: Какие типы и виды ввода/вывода доступны программе на C++?

C++ 的 I/O 系统基于**流（Stream）**的抽象概念。输入设备（键盘、磁盘、网络）产生数据流，输出设备消耗数据流。

Система ввода/вывода C++ основана на концепции **потоков (Streams)**. Устройства ввода (клавиатура, диск, сеть) генерируют поток данных, а устройства вывода потребляют его.

------

### 1. 按数据源分类 / Классификация по источнику данных

#### **A. 标准控制台 I/O / Стандартный консольный I/O (`<iostream>`)**

- **中文**: 与终端交互的标准流对象。
  - `std::cin`: 标准输入（通常是键盘）。
  - `std::cout`: 标准输出（通常是屏幕）。
  - `std::cerr`: 标准错误（无缓冲，立即输出）。
  - `std::clog`: 标准日志（有缓冲）。
- **Русский**: Стандартные объекты потоков для взаимодействия с терминалом.
  - `std::cin`: Стандартный ввод (обычно клавиатура).
  - `std::cout`: Стандартный вывод (обычно экран).
  - `std::cerr`: Стандартный поток ошибок (без буферизации, вывод мгновенно).
  - `std::clog`: Стандартный поток логов (с буферизацией).

#### **B. 文件 I/O / Файловый I/O (`<fstream>`)**

- **中文**: 用于读写磁盘文件。
  - `std::ifstream`: 输入文件流（只读）。
  - `std::ofstream`: 输出文件流（只写）。
  - `std::fstream`: 文件流（读写皆可）。
- **Русский**: Для чтения и записи файлов на диске.
  - `std::ifstream`: Поток ввода из файла (только чтение).
  - `std::ofstream`: Поток вывода в файл (только запись).
  - `std::fstream`: Файловый поток (и чтение, и запись).

#### **C. 字符串流 / Строковые потоки (`<sstream>`)**

- **中文**: 在内存中操作字符串，像操作文件一样操作 `std::string`。常用于数据类型转换（如 `int` 转 `string`）或解析。
- **Русский**: Работа со строками в памяти, как с файлами. Часто используется для преобразования типов (например, `int` в `string`) или парсинга.

#### **D. C 语言风格 / Стиль C (`<cstdio>`)**

- **中文**: 为了兼容性，C++ 支持 C 语言的 `FILE*`, `printf`, `scanf` 等。
  - *特点*: 格式控制精确，但在类型安全和扩展性上不如 C++ 流。
- **Русский**: Для совместимости C++ поддерживает `FILE*`, `printf`, `scanf` и т.д.
  - *Особенность*: Точный контроль формата, но уступает потокам C++ в безопасности типов и расширяемости.

------

### 2. 按数据形式分类 / Классификация по форме данных

#### **A. 格式化 I/O / Форматированный I/O**

- **中文**: 使用 `>>` 和 `<<` 运算符。数据会自动转换为文本形式（ASCII 或 Unicode）。
  - *例子*: 输出整数 `100` 会变成字符 `'1', '0', '0'`。
- **Русский**: Использование операторов `>>` и `<<`. Данные автоматически преобразуются в текстовый вид (ASCII или Unicode).
  - *Пример*: Вывод числа `100` превратится в символы `'1', '0', '0'`.

#### **B. 非格式化 (二进制) I/O / Неформатированный (бинарный) I/O**

- **中文**: 使用 `read()`, `write()`, `get()`, `put()` 成员函数。按字节原样读写内存数据，通常用于处理图像、音频或高效存储大块数据。
- **Русский**: Использование функций-членов `read()`, `write()`, `get()`, `put()`. Побайтовое чтение/запись данных из памяти как есть. Обычно используется для изображений, аудио или эффективного хранения больших данных.

### 代码示例 / Пример кода

C++

```c
#include <iostream>
#include <fstream>
#include <sstream>
#include <cstdio> // C-style

int main() {
    // 1. Console I/O (Formatted)
    int age;
    std::cout << "Enter age: ";
    std::cin >> age;

    // 2. String Stream (In-memory)
    std::stringstream ss;
    ss << "User age is " << age; // Int to String conversion
    std::string result = ss.str();

    // 3. File I/O (Binary/Unformatted)
    // 写入二进制文件 / Запись в бинарный файл
    std::ofstream binFile("data.bin", std::ios::binary);
    double number = 3.14159;
    binFile.write(reinterpret_cast<char*>(&number), sizeof(number));
    binFile.close();

    // 4. C-Style
    printf("Formatted string via printf: %s\n", result.c_str());

    return 0;
}
```

### 总结 / Резюме

| **形式 / Вид** | **常用类 / Классы** | **场景 / Сценарий**                                          |
| -------------- | ------------------- | ------------------------------------------------------------ |
| **Console**    | `iostream`          | 用户交互 / Взаимодействие с пользователем                    |
| **File**       | `fstream`           | 数据持久化 / Сохранение данных                               |
| **String**     | `sstream`           | 格式转换, 解析 / Конвертация, парсинг                        |
| **Binary**     | `read/write`        | 高效存储, 复杂结构 / Эффективное хранение, сложные структуры |
