## 题目 / Вопрос

- **中文**：`std::memcpy()` 和 `std::memmove()` 有什么区别？在什么情况下应该使用各自的函数？  
- **俄文**：В чём разница между `std::memcpy()` и `std::memmove()`? В каком случае используется каждая функция?

这两个函数都是 C/C++ 中用于字节级内存拷贝的标准函数，且参数完全相同。它们唯一的、也是最关键的区别在于**如何处理重叠的内存区域**。

以下是中俄互译的详细解答：

------

### 1. 核心区别 (Главное отличие)

- **std::memcpy** (Memory Copy):
  - **中文**：**不检查**内存重叠。它假设源区域（source）和目标区域（destination）**完全不重叠**。
  - **Русский**: **Не проверяет** перекрытие памяти. Предполагает, что исходная область (source) и целевая область (destination) **не перекрываются**.
  - **后果**：如果区域重叠，`memcpy` 的行为是**未定义的 (Undefined Behavior)**，可能会导致数据损坏。
  - **Последствие**: Если области перекрываются, поведение `memcpy` **не определено (UB)**, что может привести к повреждению данных.
- **std::memmove** (Memory Move):
  - **中文**：**能够安全处理**内存重叠。它保证即使源和目标区域重叠，数据也能被正确拷贝。
  - **Русский**: **Безопасно обрабатывает** перекрытие памяти. Гарантирует правильное копирование данных, даже если исходная и целевая области перекрываются.
  - **原理**：虽然名字叫 "move"（移动），但它实际上也是拷贝。它的行为就像是先将数据拷贝到一个**临时缓冲区**，然后再拷回目标地址（尽管实际实现通常通过判断拷贝方向来优化，不一定真分配缓冲区）。
  - **Принцип**: Хоть функция и называется "move" (перемещение), на самом деле это копирование. Она работает так, будто данные сначала копируются во **временный буфер**, а затем в место назначения (хотя реализация обычно оптимизирована выбором направления копирования).

------

### 2. 什么时候使用？ (Когда использовать?)

| **场景 (Сценарий)**                                          | **推荐函数 (Рекомендуемая функция)** | **原因 (Причина)**                                         |
| ------------------------------------------------------------ | ------------------------------------ | ---------------------------------------------------------- |
| **完全无关的两个数组/对象** (Два полностью независимых массива/объекта) | `std::memcpy`                        | **更快 (Faster)**。 因为它不需要做额外的检查和逻辑判断。   |
| **同一个数组内的元素位移** (Сдвиг элементов внутри одного массива) | `std::memmove`                       | **安全 (Safe)**。 源和目标地址在同一块内存块中，必然重叠。 |
| **不确定是否重叠** (Не уверены, есть ли перекрытие)          | `std::memmove`                       | **保险 (Safer)**。 宁可牺牲一点点性能，也要保证数据正确。  |

------

### 3. 用法示例 (Пример использования)

这两个函数的函数签名是一样的：

void* mem...(void* dest, const void* src, std::size_t count);

#### 情况 A：无重叠 (Нет перекрытия) -> 使用 `memcpy`

C++

```
#include <cstring>
#include <iostream>

int main() {
    char src[] = "Hello";
    char dest[6];

    // 源和目标是完全分开的内存 (Source и Dest — разные области памяти)
    std::memcpy(dest, src, 6); 
    
    std::cout << dest << std::endl; // Output: Hello
    return 0;
}
```

#### 情况 B：有重叠 (Есть перекрытие) -> 必须使用 `memmove`

这是一个典型的“数组元素向后移动”的例子。

(Это типичный пример «сдвига элементов массива назад».)

C++

```
#include <cstring>
#include <iostream>

int main() {
    int data[] = {1, 2, 3, 4, 5, 6};

    // 任务：将 {1, 2, 3} 移动到 {2, 3, 4} 的位置
    // 目标地址 (data + 1) 在 源地址 (data) 的范围内，这是重叠！
    // Задача: Переместить {1, 2, 3} на позицию {2, 3, 4}
    // Целевой адрес (data + 1) находится внутри исходного (data). Это перекрытие!

    // src:  [1, 2, 3]
    // dest:    [?, ?, ?] (data + 1)
    
    // 如果用 memcpy，可能会发生：先拷 1 覆盖了 2，下次读 2 的时候其实读到了 1... 数据乱了。
    // Если использовать memcpy: 1 перезапишет 2, и при чтении 2 мы получим 1... Данные будут испорчены.

    std::memmove(data + 1, data, 3 * sizeof(int));

    // data 现在是: {1, 1, 2, 3, 5, 6} 
    // (索引0没变，索引1-3被原来的0-2覆盖)
    
    for(int i : data) std::cout << i << " ";
    return 0;
}
```

### 总结 (Резюме)

- **`memcpy`**: 追求速度，用于**不同**内存块之间。 (Для скорости, между **разными** блоками.)
- **`memmove`**: 追求安全，用于**可能重叠**的内存块（如自我复制）。 (Для безопасности, при **возможном перекрытии**.)
