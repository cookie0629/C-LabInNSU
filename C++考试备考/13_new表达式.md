## 题目 / Вопрос

- **中文**：表达式 `new` / `new[]` 是如何工作的？  
- **俄文**：Как работает выражения `new/new[]`?

理解这一点对于理解 C++ 的异常安全性和内存模型至关重要。

`new` 表达式不仅仅是分配内存，它还负责**赋予内存生命（构造对象）**。

以下是中俄互译的详细解答：

------

### 一、 三个核心步骤 (Три основных шага)

当你写下 MyType* ptr = new MyType(); 时，编译器实际执行了以下操作：

(Когда вы пишете MyType* ptr = new MyType();, компилятор фактически выполняет следующие действия:)

#### 1. 内存分配 (Memory Allocation / Выделение памяти)

- **中文**：调用名为 `operator new` 的标准库函数（或者类重载的版本）。
  - 它的作用仅仅是申请一块足够大的**裸内存 (Raw Memory)**，类似于 C 语言的 `malloc`。
  - 此时内存里只有随机的垃圾数据。
- **Русский**：Вызывается функция стандартной библиотеки `operator new` (или перегруженная версия класса).
  - Ее задача — просто запросить блок **"сырой" памяти (Raw Memory)** достаточного размера, аналогично `malloc` в C.
  - В этот момент в памяти находятся только случайные мусорные данные.

#### 2. 对象构造 (Object Construction / Конструирование объекта)

- **中文**：在刚才分配的内存地址上，调用类的 **构造函数 (Constructor)**。
  - 这是 C++ 的魔法时刻：将裸内存变成了有效的对象。
  - 如果类有虚函数，**虚表指针 (vptr)** 也会在这一步被初始化。
- **Русский**：В только что выделенном адресе памяти вызывается **конструктор (Constructor)** класса.
  - Это момент магии C++: превращение сырой памяти в валидный объект.
  - Если у класса есть виртуальные функции, **указатель на таблицу виртуальных функций (vptr)** также инициализируется на этом этапе.

#### 3. 返回指针 (Return Pointer / Возврат указателя)

- **中文**：将指向这块构造好的内存的指针返回给用户。
- **Русский**：Пользователю возвращается указатель на эту сконструированную память.

------

### 二、 `new[]` 的特殊之处 (Особенности `new[]`)

对于数组 new MyType[N]，过程稍微复杂一点：

(Для массива new MyType[N] процесс немного сложнее:)

1. **计算总大小 (Calculate Size / Расчет размера)**：
   - `Total Size = sizeof(MyType) * N + Cookie`。
   - 需要额外的空间（Cookie）来存储数组长度 $N$，以便将来 `delete[]` 使用。
   - *(Нужно дополнительное место (Cookie) для хранения длины массива $N$, чтобы `delete[]` мог использовать его в будущем.)*
2. **分配内存 (Allocate)**：调用 `operator new[]`。
3. **循环构造 (Loop Construction)**：从数组的第一个元素到最后一个元素，依次调用构造函数。
   - *(Последовательный вызов конструкторов от первого до последнего элемента массива.)*

------

### 三、 异常处理机制 (Механизм обработки исключений)

这是 new 相比 malloc 最安全的地方。如果第 2 步（构造函数）抛出了异常，会发生什么？

(Это самое безопасное место в new по сравнению с malloc. Что произойдет, если на этапе 2 (в конструкторе) будет выброшено исключение?)

- **中文**：C++ 运行时会自动捕获这个异常，调用 `operator delete` **释放** 第 1 步分配的内存，然后再将异常抛出给用户。
  - **目的**：防止内存泄漏（即：内存分配了，但对象没建立成功，如果不自动释放，这块内存就永远丢了）。
- **Русский**：Среда выполнения C++ автоматически перехватит это исключение, вызовет `operator delete` для **освобождения** памяти, выделенной на этапе 1, а затем снова бросит исключение пользователю.
  - **Цель**: Предотвращение утечки памяти (ситуация, когда память выделена, но объект не создан; если не освободить её автоматически, она будет потеряна навсегда).

------

### 代码模拟 (Имитация кода)

编译器生成的代码逻辑大致如下：

(Логика кода, генерируемого компилятором, выглядит примерно так:)

C++

```
// 伪代码：new MyType() 的内部实现
// Псевдокод: внутренняя реализация new MyType()

MyType* ptr;

// Step 1: Allocate raw memory
// Шаг 1: Выделение сырой памяти
void* rawMemory = operator new(sizeof(MyType));

try {
    // Step 2: Construct object using "Placement New"
    // Шаг 2: Конструирование объекта с помощью "Placement New"
    
    // 在 rawMemory 地址上强行调用构造函数
    // Принудительный вызов конструктора по адресу rawMemory
    new (rawMemory) MyType(); 
    
    ptr = static_cast<MyType*>(rawMemory);
} 
catch (...) {
    // Safety Mechanism / Защитный механизм
    // If constructor fails, free the memory to avoid leak
    // Если конструктор падает, освобождаем память, чтобы избежать утечки
    operator delete(rawMemory);
    throw; // Re-throw exception to user
}

// Step 3: Return
return ptr;
```

### 总结 (Резюме)

| **步骤 (Шаг)** | **动作 (Действие)**                     | **负责组件 (Компонент)**      |
| -------------- | --------------------------------------- | ----------------------------- |
| **1**          | 分配裸内存 (Выделение сырой памяти)     | `operator new`                |
| **2**          | 初始化/构造 (Инициализация/Конструктор) | `MyType::MyType()`            |
| **3**          | 错误处理 (Обработка ошибок)             | Compiler injected `try-catch` |
