## 题目 / Вопрос

- **中文**：C++ 中有哪些机制实现运行时类型识别（RTTI）？  
- **俄文**: Какие средства C++ реализуют RTTI?

在 C++ 中，RTTI（Runtime Type Information，运行时类型信息）主要通过**虚函数表 (vtable)** 来实现。标准提供了两个主要操作符来访问这些信息。

В C++ RTTI (Runtime Type Information) реализуется в основном через **таблицу виртуальных функций (vtable)**. Стандарт предоставляет два основных оператора для доступа к этой информации.

------

### 1. `dynamic_cast`

- **中文**: 用于将基类的指针或引用安全地转换为派生类的指针或引用。
  - **机制**: 它会检查对象实际指向的内存，确认转换是否合法。
  - **结果**: 如果是指针转换失败，返回 `nullptr`；如果是引用转换失败，抛出 `std::bad_cast` 异常。
- **Русский**: Используется для безопасного приведения указателя или ссылки базового класса к производному.
  - **Механизм**: Проверяет, на что фактически указывает объект в памяти, чтобы убедиться в законности приведения.
  - **Результат**: Если приведение указателя не удается, возвращает `nullptr`; если ссылки — выбрасывает исключение `std::bad_cast`.

### 2. `typeid` Operator

- **中文**: 用于获取表达式的类型信息。它返回一个对 `std::type_info` 对象的常量引用。
  - **用途**: 比较两个对象是否属于同一类型 (`typeid(a) == typeid(b)`)，或者获取类名 (`.name()`)。
  - **注意**: 如果类**没有虚函数**，`typeid` 返回的是**编译时**的静态类型；如果**有虚函数**，它查表返回**运行时**的动态类型。
- **Русский**: Используется для получения информации о типе выражения. Возвращает константную ссылку на объект `std::type_info`.
  - **Использование**: Сравнение типов двух объектов (`typeid(a) == typeid(b)`) или получение имени класса (`.name()`).
  - **Внимание**: Если в классе **нет виртуальных функций**, `typeid` возвращает статический тип (**время компиляции**); если **есть**, он смотрит в таблицу и возвращает динамический тип (**время выполнения**).

### 3. `std::type_info` Structure

- **中文**: 这是存储类型具体信息的类（定义在 `<typeinfo>` 头文件中）。用户不能直接实例化它，只能通过 `typeid` 获取。
- **Русский**: Класс, хранящий конкретную информацию о типе (определен в заголовке `<typeinfo>`). Пользователь не может создать его экземпляр напрямую, только через `typeid`.

------

### 关键前提 / Ключевое условие

**中文**: 要使 RTTI 正常工作（即识别动态类型），基类必须**至少包含一个虚函数**（通常是虚析构函数）。否则，编译器无法在对象内存中生成 vptr（虚表指针），也就找不到类型信息。

**Русский**: Чтобы RTTI работала корректно (т.е. определяла динамический тип), базовый класс должен содержать **хотя бы одну виртуальную функцию** (обычно виртуальный деструктор). Иначе компилятор не создаст vptr (указатель на vtable) в памяти объекта и не сможет найти информацию о типе.

- 🔑 **为什么必须有虚函数？**
  - 没有虚函数 → 对象没有虚表指针（vptr）
  - 没有虚表指针 → RTTI 信息无处存储
  - 没有 RTTI 信息 → `typeid` 和 `dynamic_cast` 无法工作

------

### 代码示例 / Пример кода

C++

```c
#include <iostream>
#include <typeinfo> // Required for typeid

// 基类必须有多态性 (Virtual Function)
class Base {
public:
    virtual ~Base() {} // Virtual destructor makes it polymorphic
};

class Derived : public Base {};
class Other : public Base {};

int main() {
    Base* ptr = new Derived();

    // 1. 使用 typeid 获取运行时名称 / Использование typeid
    const std::type_info& info = typeid(*ptr);
    std::cout << "Type is: " << info.name() << std::endl; 
    // Output depends on compiler, e.g., "7Derived" or "class Derived"

    // 2. 使用 dynamic_cast 安全转换 / Использование dynamic_cast
    Derived* d = dynamic_cast<Derived*>(ptr);
    if (d) {
        std::cout << "Successfully cast to Derived" << std::endl;
    } else {
        std::cout << "Failed to cast to Derived" << std::endl;
    }

    // 尝试转换为错误的类型 / Попытка приведения к неверному типу
    Other* o = dynamic_cast<Other*>(ptr);
    if (o == nullptr) {
        std::cout << "ptr is NOT an Other class" << std::endl;
    }

    delete ptr;
    return 0;
}
```
