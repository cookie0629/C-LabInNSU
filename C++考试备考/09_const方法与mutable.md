## 题目 / Вопрос

- **中文**：常量成员函数（`const` 成员函数）有什么用？在什么情况下会被调用？在自定义类型定义中，关键字 `mutable` 有什么用途？  
- **俄文**: Для чего нужен константный метод и когда он будет вызван? Для чего используется ключевое слово `mutable` в рамках определения пользовательского типа данных?

这是一个关乎代码安全性（Const-correctness）和底层设计模式的重要问题。

以下是中俄互译的详细解答：

------

### 一、 常量成员函数 (Const Member Functions / Константные методы)

#### 1. 有什么用？ (Для чего нужны?)

- **中文**：
  1. **承诺不修改**：它向编译器和读代码的人保证，这个函数**不会修改**对象的任何非静态数据成员（Bitwise Constness）。
  2. **扩大适用范围**：只有标记为 `const` 的函数，才能被 **`const` 对象**（或 `const` 指针/引用）调用。如果一个对象是常量的，它就不能调用任何非 `const` 的成员函数。
  3. **底层原理**：在 `const` 函数内部，`this` 指针的类型从 `Type* const` 变成了 `const Type* const`（指向常量的常量指针）。
- **Русский**：
  1. **Гарантия неизменности**: Метод обещает компилятору и программисту, что он **не изменит** никакие нестатические члены данных объекта (побитовая константность).
  2. **Расширение применимости**: Только методы, помеченные как `const`, могут быть вызваны у **`const` объектов** (или через `const` указатели/ссылки). Если объект константный, он не может вызывать неконстантные методы.
  3. **Механизм**: Внутри `const` метода тип указателя `this` меняется с `Type* const` на `const Type* const` (константный указатель на константу).

#### 2. 什么时候会被调用？ (Когда вызываются?)

- **中文**：
  - 当通过 `const` 对象、`const` 引用或 `const` 指针调用该函数时，**必须**调用 `const` 版本。
  - **重载 (Overloading)**：如果一个类同时拥有同名的 `const` 和非 `const` 版本：
    - 普通对象优先调用 **非 `const`** 版本。
    - 常量对象只能调用 **`const`** 版本。
- **Русский**：
  - Когда метод вызывается через `const` объект, `const` ссылку или `const` указатель, **обязательно** вызывается `const` версия.
  - **Перегрузка (Overloading)**: Если класс имеет и `const`, и не-`const` версии одного метода:
    - Обычные объекты предпочитают **не-`const`** версию.
    - Константные объекты могут вызывать только **`const`** версию.

------

### 二、 关键字 mutable (Ключевое слово mutable)

#### 用途 (Назначение)

- 中文：

  mutable 意思是“易变的”。它的作用是突破 const 的限制。

  被标记为 mutable 的成员变量，即使在 const 成员函数内部，也可以被修改。

  常见场景：用于 "逻辑常量性" (Logical Constness)。

  即：对象从外部看状态没有变（比如没有改变形状、大小），但在内部进行了某些由于技术原因需要的修改。例如：

  1. **缓存 (Caching)**：计算结果很耗时，第一次算完存下来，下次直接用。虽修改了缓存变量，但对象的“值”没变。
  2. **互斥锁 (Mutex)**：即使读取数据（const操作），也需要上锁（修改 mutex 状态）。

- Русский：

  mutable означает «изменчивый». Его цель — преодолеть ограничение const.

  Переменные-члены, помеченные как mutable, могут быть изменены даже внутри const методов.

  Типичный сценарий: Реализация «логической константности» (Logical Constness).

  То есть: объект внешне не меняется (например, не меняет форму или размер), но внутри происходят изменения по техническим причинам. Например:

  1. **Кэширование (Caching)**: Вычисления занимают много времени, результат сохраняется для повторного использования. Кэш изменился, но «значение» объекта — нет.
  2. **Мьютексы (Mutex)**: Даже при чтении данных (const операция) нужно захватить мьютекс (изменить его состояние).

------

### 三、 代码示例 (Пример кода)

这个例子展示了如何在 const 函数中修改 mutable 变量（模拟缓存机制）。

(Этот пример показывает, как изменить переменную mutable внутри const функции (имитация кэширования).)

C++

```
#include <iostream>

class MathObject {
private:
    int data;
    // mutable 允许在 const 函数中被修改
    // (mutable позволяет изменение внутри const метода)
    mutable int cacheValue; 
    mutable bool isCacheValid;

public:
    MathObject(int v) : data(v), cacheValue(0), isCacheValid(false) {}

    // const 成员函数 (Константный метод)
    int calculate() const {
        // 如果我们试图修改 data = 5; 会报错！
        // (Если попытаться data = 5;, будет ошибка!)

        if (!isCacheValid) {
            std::cout << "Calculating (expensive operation)...\n";
            // 修改 mutable 成员是合法的
            // (Изменение mutable члена допустимо)
            cacheValue = data * data; 
            isCacheValid = true;
        } else {
            std::cout << "Using cached value...\n";
        }
        return cacheValue;
    }

    // 用于重置数据的非 const 函数
    // (Неконстантный метод для сброса данных)
    void setData(int v) {
        data = v;
        isCacheValid = false; // Invalidating cache
    }
};

int main() {
    const MathObject obj(10); // const 对象 (const объект)

    // 调用 const 函数，但在内部修改了 mutable 变量
    // (Вызов const метода, но внутри меняются mutable переменные)
    std::cout << "Result: " << obj.calculate() << std::endl; 
    std::cout << "Result: " << obj.calculate() << std::endl; 

    return 0;
}
```

### 总结 (Резюме)

| **概念 (Понятие)**    | **作用 (Роль)**                                              |
| --------------------- | ------------------------------------------------------------ |
| **const Method**      | 保护对象状态，允许 const 对象调用。(Защищает состояние, разрешает вызов для const объектов.) |
| **mutable**           | 允许特定的成员在 const 方法中被修改（如缓存、锁）。(Разрешает изменение конкретных членов в const методах (кэш, лок).) |
| **Logical Constness** | 外部看起来没变，内部可能变了（依靠 mutable 实现）。(Внешне неизменно, внутри меняется (через mutable).) |
