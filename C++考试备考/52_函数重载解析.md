## 题目 / Вопрос

- **中文**：在 C++ 中，什么是“重载函数”？调用重载函数时，解析过程是怎样的？  
- **俄文**: Что такое и как происходит вызов перегруженной функции в C++?

**重载函数（Overloaded Functions）** 是 C++ 静态多态性（Static Polymorphism）的一种形式。**重载解析（Overload Resolution）** 是编译器决定调用哪个函数的复杂过程。

**Перегруженные функции (Overloaded Functions)** — это форма статического полиморфизма в C++. **Разрешение перегрузки (Overload Resolution)** — это сложный процесс, в ходе которого компилятор решает, какую именно функцию вызвать.

------

### 1. 什么是重载函数？ / Что такое перегруженная функция?

- **定义**: 在**同一作用域**内，函数名相同但**参数列表不同**（参数个数、类型或顺序不同）的函数。
- **规则**:
  - 仅仅**返回值类型不同**不足以构成重载。
  - 成员函数的 `const` 限定符可以区分重载（针对 `this` 指针的类型不同）。
- **Определение**: Функции с **одинаковым именем**, но **разными списками параметров** (количество, тип или порядок), объявленные в **одной области видимости**.
- **Правила**:
  - Различия только в **типе возвращаемого значения** недостаточно для перегрузки.
  - Квалификатор `const` у методов класса позволяет перегрузку (так как меняется тип указателя `this`).

------

### 2. 重载解析过程 / Процесс разрешения перегрузки

当编译器看到 func(arg) 时，它会按以下三个步骤进行匹配：

Когда компилятор видит вызов func(arg), он выполняет сопоставление в три этапа:

#### **Step 1: 查找候选函数 / Поиск функций-кандидатов (Candidate Functions)**

- **中文**: 编译器查找所有与被调用函数**同名**且在当前调用点**可见**的函数。
- **Русский**: Компилятор ищет все функции с **таким же именем**, которые **видны** в точке вызова.

#### **Step 2: 确定可行函数 / Определение подходящих функций (Viable Functions)**

- **中文**: 从候选函数中筛选出参数数量匹配，且参数类型可以**隐式转换**为形参类型的函数。
- **Русский**: Из кандидатов отбираются те, у которых совпадает количество аргументов, и типы аргументов могут быть **неявно преобразованы** в типы параметров.

#### **Step 3: 寻找最佳匹配 / Поиск наилучшего совпадения (Best Match)**

- **中文**: 编译器会计算每个可行函数的“匹配代价”，并选择代价最小的一个。如果没有一个唯一的最佳匹配（即有两个同样好的匹配），则报错“**二义性调用**” (Ambiguous call)。
- **Русский**: Компилятор рассчитывает «стоимость» совпадения для каждой функции и выбирает ту, где стоимость минимальна. Если нет единственного лучшего совпадения (два одинаково хороши), выдается ошибка «**неоднозначный вызов**».

------

### 3. 匹配优先级排名 / Ранжирование приоритетов совпадения

编译器按照以下顺序判断哪个匹配更好（从优到劣）：

Компилятор оценивает качество совпадения в следующем порядке (от лучшего к худшему):

1. **精确匹配 (Exact Match)**: 类型完全相同（包括加上 const/ref 等微小调整）。
   - *RU: Точное совпадение.*
2. **提升 (Promotion)**:
   - `char`, `short` -> `int`
   - `float` -> `double`
   - *RU: Продвижение типов (расширение).*
3. **标准转换 (Standard Conversion)**:
   - `int` -> `double`, `double` -> `int`
   - `Derived*` -> `Base*` (子类指针转基类指针)
   - *RU: Стандартное преобразование.*
4. **用户自定义转换 (User-defined Conversion)**:
   - 利用构造函数或类型转换运算符进行的转换。
   - *RU: Пользовательское преобразование.*
5. **省略号匹配 (Ellipsis)**:
   - C 风格的可变参数 `...`。
   - *RU: Совпадение с многоточием.*

### 代码示例 / Пример кода

C++

```c
#include <iostream>

void func(int i) { std::cout << "Exact Match: int" << std::endl; }
void func(double d) { std::cout << "Exact Match: double" << std::endl; }
void func(long l) { std::cout << "Exact Match: long" << std::endl; }

int main() {
    func(10);      // Calls func(int) -> Exact Match
    func(3.14);    // Calls func(double) -> Exact Match

    short s = 5;
    func(s);       // Calls func(int) -> Integral Promotion (short promotes to int)
                   // 调用 func(int) -> 整型提升

    float f = 1.0f;
    func(f);       // Calls func(double) -> Floating Point Promotion
                   // 调用 func(double) -> 浮点提升

    // Ambiguity Example / 二义性示例
    // func(NULL); 
    // Error: NULL is 0 (int), but could be null pointer representation? 
    // In C++11, use nullptr to fix this.
    
    return 0;
}
```

### 关键陷阱 / Ключевая ловушка

中文: 整型提升（Promotion）优于标准转换（Conversion）。

例如：如果只有 void f(int) 和 void f(double)，调用 f(short) 会优先选择 int 版本（提升），而不是 double 版本（转换）。

Русский: Продвижение (Promotion) лучше, чем преобразование (Conversion).

Например: если есть только void f(int) и void f(double), вызов f(short) выберет версию int (продвижение), а не double (преобразование).
