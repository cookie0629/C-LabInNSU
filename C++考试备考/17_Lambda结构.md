## 题目 / Вопрос

- **中文**：Lambda 表达式由哪些部分（块）组成？每一部分的作用和特点是什么？  
- **俄文**: Какие блоки лямбда-выражения вы знаете? В чем состоит их задача и особенности?

C++ Lambda 表达式（匿名函数）的语法结构非常紧凑且灵活。它通常由 **5 个主要部分** 组成，虽然其中只有“捕获列表”和“函数体”是绝对必须的。

完整的语法形式如下：

[captures] (params) specifiers -> ret_type { body }

以下是中俄互译的详细结构分解：

------

### 1. 捕获列表 (Capture Clause / Список захвата) `[]`

这是 Lambda 的标志，必须始终存在。

(Это признак лямбды, он должен присутствовать всегда.)

- **作用 (Задача)**：
  - **中文**：定义 Lambda 内部如何访问**外部作用域**的变量。它是连接“外部世界”和“函数内部”的桥梁。
  - **Русский**：Определяет, как лямбда получает доступ к переменным из **внешней области видимости**. Это мост между «внешним миром» и «внутренней частью функции».
- **特点 (Особенности)**：
  - `[ ]`: 不捕获任何变量 (Ничего не захватывать).
  - `[=]`: 按**值**捕获所有外部变量 (Захват всего по **значению**).
  - `[&]`: 按**引用**捕获所有外部变量 (Захват всего по **ссылке**).
  - `[x, &y]`: `x` 按值，`y` 按引用 (x — по значению, y — по ссылке).
  - *注意：这是 C++ Lambda 与普通函数最大的区别。*

### 2. 参数列表 (Parameter List / Список параметров) `()`

- **作用 (Задача)**：
  - **中文**：声明运行时调用 Lambda 时需要传入的参数。与普通函数完全一样。
  - **Русский**：Объявляет аргументы, которые нужно передать при вызове лямбды. Точно так же, как у обычной функции.
- **特点 (Особенности)**：
  - 如果不需要参数，`()` 可以省略（除非使用了 `mutable`）。
  - **C++14 特性**：可以使用 `auto`（泛型 Lambda），例如 `(auto x, auto y)`。
  - *(Если аргументы не нужны, `()` можно опустить (кроме случаев с `mutable`). В C++14 можно использовать `auto` (обобщенная лямбда).)*

### 3. 可变规范 (Mutable Specification / Спецификатор mutable) `mutable`

这是一个容易被忽视但非常重要的部分。

(Это часто упускаемая из виду, но очень важная часть.)

- **作用 (Задача)**：
  - **中文**：允许修改**按值捕获**的变量。
  - **Русский**：Разрешает изменять переменные, захваченные **по значению**.
- **特点 (Особенности)**：
  - 默认情况下，Lambda 生成的函数对象（Functor）的调用运算符是 `const` 的。这意味着你不能修改通过 `=` 捕获进来的副本。
  - 加上 `mutable` 后，移除了 `const` 属性，允许修改副本。
  - *(По умолчанию оператор вызова лямбды — `const`. Это значит, что нельзя менять копии, захваченные через `=`. `mutable` снимает это ограничение.)*

### 4. 返回类型 (Trailing Return Type / Тип возвращаемого значения) `-> type`

- **作用 (Задача)**：
  - **中文**：显式指定函数的返回类型。
  - **Русский**：Явное указание типа возвращаемого значения функции.
- **特点 (Особенности)**：
  - 通常可以**省略**，编译器会自动推导（Type Deduction）。
  - 当函数体包含多个 `return` 语句且类型不一致，或者逻辑非常复杂时，必须显式写出。
  - *(Обычно можно **опустить**, компилятор выведет тип сам. Требуется явно, если в теле несколько `return` с разными типами или сложная логика.)*

### 5. 函数体 (Lambda Body / Тело лямбды) `{}`

- **作用 (Задача)**：
  - **中文**：包含实际执行的代码逻辑。
  - **Русский**：Содержит фактически исполняемый код.
- **特点 (Особенности)**：
  - 可以访问捕获的变量和传入的参数。
  - *(Имеет доступ к захваченным переменным и переданным аргументам.)*

------

### 代码解剖 (Разбор кода)

C++

```
#include <iostream>

int main() {
    int outer_val = 10;

    //  1. Capture   2. Params      3. Spec     4. Ret     5. Body
    //  [========]  (_________)    _______    _______    {________}
    auto lambda = [outer_val] (int x) mutable -> int {
        
        // 因为加了 mutable，我们可以修改 outer_val (它是副本)
        // (Благодаря mutable мы можем менять outer_val (это копия))
        outer_val += 5; 
        
        return outer_val + x;
    };

    std::cout << lambda(20) << std::endl; // Output: 35 (10+5 + 20)
    std::cout << outer_val << std::endl;  // Output: 10 (Original not changed)

    return 0;
}
```

### 总结 (Резюме)

| **组成部分 (Блок)** | **必须? (Обязательно?)** | **核心功能 (Основная функция)**                              |
| ------------------- | ------------------------ | ------------------------------------------------------------ |
| **`[]`**            | **Yes**                  | 闭包的定义，捕获上下文变量 (Определение замыкания, захват контекста) |
| **`()`**            | No                       | 接收运行时参数 (Прием аргументов времени выполнения)         |
| **`mutable`**       | No                       | 允许修改值捕获的副本 (Разрешает изменение копий)             |
| **`-> type`**       | No                       | 指定返回类型 (Указание возвращаемого типа)                   |
| **`{}`**            | **Yes**                  | 执行逻辑 (Логика выполнения)                                 |

`auto` 起到了**自动类型推导**的作用: 因为**每个 lambda 表达式都有唯一的、编译器生成的类型**，我们无法直接写出它的类型名。
