## 题目 / Вопрос

- **中文**：C++ 中的函数具有什么性质？请详细描述这些性质。  
- **俄文**: Какими свойствами обладают функции в C++? Опишите свойства в деталях.

C++ 中的函数不仅是代码的模块化单元，还拥有比 C 语言更丰富、更灵活的特性。以下是 C++ 函数的核心性质。

Функции в C++ — это не просто модульные единицы кода, они обладают гораздо более богатыми и гибкими свойствами, чем в C. Ниже приведены основные характеристики функций в C++.

------

### 1. 函数重载 / Перегрузка функций (Function Overloading)

- **中文**: C++ 允许在同一作用域内定义多个**同名函数**，只要它们的**参数列表不同**（参数个数或类型不同）。这被称为“静态多态”。
  - *注意*: 不能仅通过返回值类型不同来重载函数。
- **Русский**: C++ позволяет определять несколько функций с **одним и тем же именем** в одной области видимости, при условии, что их **списки параметров различаются** (количество или типы). Это называется «статический полиморфизм».
  - *Примечание*: Нельзя перегружать функции, различающиеся только типом возвращаемого значения.

### 2. 参数传递方式 / Способы передачи параметров

- **中文**: 除了标准的**值传递**（传拷贝）和**指针传递**，C++ 引入了**引用传递 (Pass-by-Reference)**。
  - **引用传递**: 允许函数直接操作调用者的变量，而无需指针解引用语法，且避免了复制大对象的开销。
- **Русский**: Помимо стандартной **передачи по значению** (копия) и **по указателю**, C++ ввел **передачу по ссылке (Pass-by-Reference)**.
  - **Передача по ссылке**: Позволяет функции работать напрямую с переменной вызывающего кода без синтаксиса разыменования указателей и избегая накладных расходов на копирование больших объектов.

### 3. 默认参数 / Аргументы по умолчанию (Default Arguments)

- **中文**: 函数声明时可以为参数指定默认值。如果调用时省略了该参数，编译器会自动使用默认值。
  - *规则*: 默认参数必须从右向左连续定义。
- **Русский**: При объявлении функции можно указать значения по умолчанию для параметров. Если при вызове аргумент опущен, компилятор автоматически использует значение по умолчанию.
  - *Правило*: Аргументы по умолчанию должны определяться последовательно справа налево.

### 4. 内联函数 / Встраиваемые функции (Inline Functions)

- **中文**: 使用 `inline` 关键字建议编译器将函数体直接**展开**到调用处，而不是进行常规的函数调用（压栈、跳转）。这用于优化小型、高频调用的函数。
- **Русский**: Ключевое слово `inline` советует компилятору **вставить** тело функции прямо в место вызова, вместо выполнения обычного вызова функции (стек, переход). Используется для оптимизации небольших, часто вызываемых функций.

### 5. `const` 成员函数 / `const` методы-члены

- **中文**: 在类中，标记为 `const` 的成员函数承诺**不修改对象的任何成员变量**。这使得该函数可以在 `const` 对象上被调用。
- **Русский**: В классах методы, помеченные как `const`, обещают **не изменять переменные-члены объекта**. Это позволяет вызывать такие методы у `const` объектов.

### 代码示例 / Пример кода

C++

```c
#include <iostream>
#include <string>

// 1. Inline Function / 内联函数
inline int add(int a, int b) {
    return a + b;
}

// 2. Function Overloading / 函数重载
void print(int i) {
    std::cout << "Integer: " << i << std::endl;
}

void print(std::string s) {
    std::cout << "String: " << s << std::endl;
}

// 3. Default Arguments & Pass-by-Reference / 默认参数与引用传递
// "greeting" has a default value. "name" is passed by const reference (efficient).
void greet(const std::string& name, std::string greeting = "Hello") {
    std::cout << greeting << ", " << name << "!" << std::endl;
}

class Counter {
    int count = 0;
public:
    // 4. Const Member Function / Const 成员函数
    int getCount() const {
        // count++; // Error: cannot modify in a const function
        return count;
    }
};

int main() {
    print(42);           // Calls print(int)
    print("Test");       // Calls print(string)
    
    greet("Alice");              // Uses default: "Hello, Alice!"
    greet("Bob", "Good morning");// Overrides default
    
    return 0;
}
```

### 总结 / Резюме

| **性质 / Свойство**   | **C 语言支持? / Есть в C?** | **优势 / Преимущество**                           |
| --------------------- | --------------------------- | ------------------------------------------------- |
| **Overloading**       | ❌ No                        | 提高代码可读性 (同名异义) / Читаемость кода       |
| **References**        | ❌ No                        | 语法简洁，避免空指针 / Чистый синтаксис, без null |
| **Default Args**      | ❌ No                        | 减少函数版本数量 / Меньше версий функций          |
| **Inline**            | ✅ Yes (C99)                 | 消除调用开销 / Устранение оверхеда вызова         |
| **Const Correctness** | ❌ No (Strictly)             | 接口契约更安全 / Безопасность интерфейса          |
