## 题目 / Вопрос

- **中文**：在 C++ 中，什么是“对象的生命周期”（object lifetime）？  
- **俄文**: Что такое время жизни объекта в C++?

在 C++ 中，**对象的生命周期（Object Lifetime）** 是指程序执行过程中，该对象保证在内存中存在并保留其值的**时间区间**。

В C++ **время жизни объекта (Object Lifetime)** — это **интервал времени** выполнения программы, в течение которого объект гарантированно существует в памяти и сохраняет свое значение.

### 1. 核心定义 / Основное определение

- **起点 / Начало**: 对象的构造函数**成功执行完毕**的那一刻。
- **终点 / Конец**: 对象的析构函数**开始执行**的那一刻。
- **危险 / Опасность**: 在这个时间区间之外访问该对象（例如通过悬空指针），属于**未定义行为 (Undefined Behavior)**。
- **Начало**: Момент, когда конструктор объекта **успешно завершил выполнение**.
- **Конец**: Момент, когда деструктор объекта **начинает выполнение**.
- **Опасность**: Доступ к объекту вне этого интервала (например, через висячий указатель) является **неопределенным поведением (UB)**.

------

### 2. 四种存储期 / 4 типа продолжительности хранения

对象的生命周期由它的**存储期（Storage Duration）**决定：

Время жизни объекта определяется его продолжительностью хранения (Storage Duration):

#### **A. 自动存储期 (Automatic)**

- **对应**: 局部变量（非 static）。
- **生命周期**: 从声明点开始，到代码执行离开所在的**作用域 (`{ ... }`)** 为止。通常存储在**栈**上。
- **Соответствие**: Локальные переменные (не static).
- **Время жизни**: От объявления до выхода выполнения из **области видимости (`{ ... }`)**. Обычно хранятся в **стеке**.

#### **B. 静态存储期 (Static)**

- **对应**: 全局变量、`static` 局部变量、类 `static` 成员。
- **生命周期**: 从程序启动（或第一次执行到声明处）开始，直到**程序结束**（`main` 返回后）才销毁。
- **Соответствие**: Глобальные переменные, `static` локальные переменные, `static` члены класса.
- **Время жизни**: От запуска программы (или первого использования) до **завершения программы** (после возврата из `main`).

#### **C. 动态存储期 (Dynamic)**

- **对应**: 通过 `new` 分配的对象。
- **生命周期**: 从 `new` 成功开始，直到显式调用 `delete` 为止。这是最灵活但也最危险的，容易导致内存泄漏。
- **Соответствие**: Объекты, созданные через `new`.
- **Время жизни**: От успешного `new` до явного вызова `delete`. Самый гибкий, но опасный тип (риск утечек памяти).

#### **D. 线程存储期 (Thread)**

- **对应**: 使用 `thread_local` 关键字声明的变量。
- **生命周期**: 与**线程**的生命周期绑定。线程创建时初始化，线程结束时销毁。
- **Соответствие**: Переменные с ключевым словом `thread_local`.
- **Время жизни**: Привязано к жизни **потока**. Создаются при старте потока, умирают при его завершении.

------

### 代码示例 / Пример кода

C++

```c
#include <iostream>

// 1. Static Duration (Global)
// 静态存储期：程序结束时销毁
int globalVar = 0; 

void function() {
    // 2. Automatic Duration (Stack)
    // 自动存储期：函数结束时销毁
    int stackVar = 10; 

    // 3. Dynamic Duration (Heap)
    // 动态存储期：手动 delete 时销毁
    int* heapVar = new int(20);
    
    // 4. Thread Duration
    // 线程存储期：线程结束时销毁
    thread_local int threadVar = 5;

    delete heapVar; // heapVar 的生命周期在此结束 / Жизнь heapVar заканчивается здесь
} // stackVar 的生命周期在此结束 / Жизнь stackVar заканчивается здесь

int main() {
    function();
    return 0;
} // globalVar 的生命周期在此结束 / Жизнь globalVar заканчивается здесь
```
