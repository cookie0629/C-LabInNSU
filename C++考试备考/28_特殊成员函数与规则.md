## 题目 / Вопрос

- **中文**：对于用户自定义类型，定义了哪些“特殊成员函数”？“五法则（Rule of Five）”和“零法则（Rule of Zero）”各自表达了什么思想？  
- **俄文**: Какие определены специальные функции-члены пользовательского типа данных? Что выражают идиомы «Правило пяти» и «Правило нуля»?

这是现代 C++ 资源管理（Resource Management）最核心的指导原则。它们决定了你编写的类是否安全、高效且没有内存泄漏。

以下是中俄互译的详细解答：

------

### 一、 六大特殊成员函数 (Шесть специальных функций-членов)

在 C++11 及以后，编译器会自动为你生成（如果你不手动定义的话）以下 6 个函数。

(В C++11 и новее компилятор автоматически генерирует следующие 6 функций (если вы не определите их вручную).)

1. **默认构造函数 (Default Constructor)**: `Class();`
2. **析构函数 (Destructor)**: `~Class();`
3. **拷贝构造函数 (Copy Constructor)**: `Class(const Class&);`
4. **拷贝赋值运算符 (Copy Assignment Operator)**: `Class& operator=(const Class&);`
5. **移动构造函数 (Move Constructor)**: `Class(Class&&);` *(C++11)*
6. **移动赋值运算符 (Move Assignment Operator)**: `Class& operator=(Class&&);` *(C++11)*

------

### 二、 五法则 (Rule of Five / Правило пяти)

这是 C++98 "三法则 (Rule of Three)" 在 C++11 中的扩展。

(Это расширение «Правила трёх» из C++98 для C++11.)

- **核心思想 (Core Idea)**:
  - **中文**: 如果你需要手动定义 **析构函数**（通常是因为类内部管理了原始指针 `raw pointer`，需要在析构时 `delete`），那么你**几乎一定**需要手动定义其他四个函数（拷贝构造、拷贝赋值、移动构造、移动赋值）。
  - **Русский**: Если вам нужно вручную определить **деструктор** (обычно потому, что класс управляет «сырым» указателем и должен вызвать `delete`), то вам **почти наверняка** нужно определить и остальные четыре функции (копирование и перемещение).
- **为什么？ (Why?)**:
  - **中文**: 因为编译器默认生成的“拷贝”只是**浅拷贝 (Shallow Copy)**（只复制指针地址）。如果两个对象拥有相同的指针，析构时会导致 **双重释放 (Double Free)** 的崩溃。因此，你需要手动实现**深拷贝 (Deep Copy)**。而既然你实现了深拷贝，为了性能，你也应该实现移动操作来支持资源转移。
  - **Русский**: Потому что «копирование», генерируемое компилятором по умолчанию, — это **поверхностное копирование** (копируется только адрес указателя). Если два объекта владеют одним указателем, при уничтожении произойдет **двойное освобождение (Double Free)**. Поэтому нужно реализовать **глубокое копирование**. А раз уж вы это делаете, для производительности стоит реализовать и операции перемещения.

------

### 三、 零法则 (Rule of Zero / Правило нуля)

这是现代 C++ (Modern C++) 最推崇的设计模式。

(Это наиболее рекомендуемый паттерн проектирования в современном C++.)

- **核心思想 (Core Idea)**:

  - **中文**: **尽量不要**在你的类中定义任何特殊成员函数（析构、拷贝、移动等）。
  - **Русский**: **Старайтесь не** определять никаких специальных функций-членов (деструктор, копирование, перемещение и т.д.) в вашем классе.

- **如何做到？ (How?)**:

  - 中文: 使用 RAII 包装器 来管理资源。

    不要直接用 int* ptr，而是用 std::unique_ptr<int> 或 std::vector<int>。

    因为 std::unique_ptr 和 std::vector 已经正确实现了“五法则”。如果你的类只包含这些成员，编译器自动生成的默认函数就会调用这些成员的正确行为。

  - Русский: Используйте RAII-обертки для управления ресурсами.

    Вместо int* ptr используйте std::unique_ptr<int> или std::vector<int>.

    Так как std::unique_ptr и std::vector уже правильно реализуют «Правило пяти», компилятор сгенерирует дефолтные функции, которые будут корректно вызывать поведение этих членов.

------

### 代码对比 (Сравнение кода)

#### 1. 五法则 (Rule of Five) - 手动管理内存 (Old School / Low Level)

C++

```c
#include <utility>
#include <algorithm>

class ManualBuffer {
    int* data;
    size_t size;

public:
    // 1. 构造 (Constructor)
    ManualBuffer(size_t s) : size(s), data(new int[s]) {}

    // 2. 析构 (Destructor) - 必须写！
    ~ManualBuffer() { delete[] data; }

    // 3. 拷贝构造 (Copy Constructor) - 必须写！(深拷贝)
    ManualBuffer(const ManualBuffer& other) : size(other.size), data(new int[other.size]) {
        std::copy(other.data, other.data + size, data);
    }

    // 4. 拷贝赋值 (Copy Assignment) - 必须写！
    ManualBuffer& operator=(const ManualBuffer& other) {
        if (this != &other) {
            delete[] data;
            size = other.size;
            data = new int[size];
            std::copy(other.data, other.data + size, data);
        }
        return *this;
    }

    // 5. 移动构造 (Move Constructor) - 推荐写 (性能)
    ManualBuffer(ManualBuffer&& other) noexcept : data(other.data), size(other.size) {
        other.data = nullptr; // 窃取资源
        other.size = 0;
    }

    // 6. 移动赋值 (Move Assignment) - 推荐写
    ManualBuffer& operator=(ManualBuffer&& other) noexcept {
        if (this != &other) {
            delete[] data;
            data = other.data;
            size = other.size;
            other.data = nullptr;
            other.size = 0;
        }
        return *this;
    }
};
```

#### 2. 零法则 (Rule of Zero) - 现代方式 (Modern Way)

C++

```c
#include <vector>

class ModernBuffer {
    // std::vector 已经处理了所有内存管理逻辑
    // (std::vector уже обрабатывает всю логику управления памятью)
    std::vector<int> data; 

public:
    ModernBuffer(size_t size) : data(size) {}

    // 不需要写析构函数，不需要写拷贝/移动...
    // 编译器生成的默认版本会自动调用 vector 的对应函数
    // (Не нужно писать деструктор, копирование/перемещение...
    // Сгенерированные компилятором версии вызовут функции вектора)
};
```

### 总结 (Резюме)

| **场景 (Сценарий)**                     | **采用法则 (Правило)** | **行动 (Действие)**                                      |
| --------------------------------------- | ---------------------- | -------------------------------------------------------- |
| **普通的业务类** (Business Logic Class) | **Rule of Zero**       | 只使用 `vector`, `string`, `smart_ptr`。**什么都不写**。 |
| **底层资源封装类** (Resource Wrapper)   | **Rule of Five**       | 手动管理 `raw pointer` 或系统句柄。**全都要写**。        |
