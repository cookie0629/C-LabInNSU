## 题目 / Вопрос

- **中文**：你知道哪些 C++ 编译器？一个典型的编译器发行包通常包含哪些组件？  
- **俄文**: Какие компиляторы для C++ вы знаете? Что входит в типичный состав поставки для компилятора?

C++ 的生态系统中，"编译器"通常指代一套完整的**工具链 (Toolchain)**。目前市场上有“三大主流”编译器，以及一些特定平台的变体。

以下是中俄互译的详细介绍：

------

### 一、 三大主流编译器 (Большая тройка компиляторов)

#### 1. GCC (GNU Compiler Collection)

- **平台**: Linux (标准), Unix, Windows (通过 MinGW).
- **中文**: 开源界的霸主，历史最悠久，支持的架构最多。它是 Linux 系统下的默认编译器。
- **Русский**: Лидер в мире Open Source, с самой долгой историей и поддержкой наибольшего количества архитектур. Стандартный компилятор для Linux.
- **Command**: `g++`

#### 2. Clang (LLVM)

- **平台**: macOS (默认), Linux, Windows, Android.
- **中文**: 基于 LLVM 架构。以**编译速度快**、**内存占用低**和**报错信息极其友好**而闻名。它是 Apple 系统的默认编译器，也是 Google 的首选。
- **Русский**: Основан на архитектуре LLVM. Известен **высокой скоростью компиляции**, **низким потреблением памяти** и **очень понятными сообщениями об ошибках**. Стандарт для Apple и выбор Google.
- **Command**: `clang++`

#### 3. MSVC (Microsoft Visual C++)

- **平台**: Windows 专用.
- **中文**: 集成在 Visual Studio 中。它是 Windows 平台上开发 C++（尤其是涉及 Windows API 或 MFC 时）的事实标准。
- **Русский**: Встроен в Visual Studio. Это стандарт де-факто для разработки на C++ под Windows (особенно при работе с Windows API или MFC).
- **Command**: `cl.exe`

------

### 二、 编译器发行包的组成 (Состав дистрибутива компилятора)

当你安装上述任何一个编译器时，你不仅仅得到了一个把 `.cpp` 变成机器码的程序，你得到是一整套工具：

#### 1. 预处理器 (Preprocessor / Препроцессор)

- **功能**: 处理以 `#` 开头的指令（如 `#include`, `#define`），进行文本替换。
- **Функция**: Обрабатывает директивы, начинающиеся с `#` (например, `#include`, `#define`), выполняя текстовую подстановку.

#### 2. 编译器核心 (Compiler / Компилятор)

- **功能**: 将预处理后的代码翻译成**汇编语言**，再翻译成**机器码**（生成目标文件 `.o` 或 `.obj`）。
- **Функция**: Переводит предобработанный код в **ассемблер**, а затем в **машинный код** (создавая объектные файлы `.o` или `.obj`).

#### 3. 链接器 (Linker / Компоновщик)

- **功能**: 将多个目标文件和库文件（Static Libs）“缝合”在一起，生成最终的可执行文件 (`.exe` 或 `.out`)。它负责解析符号地址。
- **Функция**: «Сшивает» несколько объектных файлов и библиотек (Static Libs) вместе, создавая конечный исполняемый файл. Отвечает за разрешение адресов символов.
- *Tools*: `ld` (GNU), `link.exe` (MSVC).

#### 4. 标准库实现 (Standard Library Implementation / Реализация стандартной библиотеки)

- **功能**: 包含了 C++ 标准规定的头文件（`<vector>`, `<iostream>`）和预编译好的二进制库文件。
- **Функция**: Содержит заголовочные файлы (`<vector>`, `<iostream>`) и скомпилированные бинарные библиотеки, предписанные стандартом C++.
- *Examples*: `libstdc++` (GCC), `libc++` (LLVM), `MSVC STL`.

#### 5. 运行时库 (Runtime Library / Библиотека времени выполнения)

- **功能**: 支持程序运行的基础代码，包括程序启动入口（main 之前运行的代码）、异常处理机制、内存分配 (`malloc/new`) 实现等。
- **Функция**: Базовый код для запуска программы (код до main), обработка исключений, реализация выделения памяти (`malloc/new`) и т.д.
- *Examples*: `CRT` (C Runtime).

#### 6. 辅助工具 (Binary Utilities / Вспомогательные утилиты)

- **功能**: 用于检查生成的二进制文件。
- **Функция**: Инструменты для анализа бинарных файлов.
- *Examples*:
  - **调试器 (Debugger)**: `gdb`, `lldb`.
  - **符号查看器**: `nm`, `dumpbin`.
  - **反汇编器**: `objdump`.

### 总结 (Резюме)

| **组件 (Компонент)** | **作用 (Роль)**               | **GCC/Clang 对应**     | **MSVC 对应** |
| -------------------- | ----------------------------- | ---------------------- | ------------- |
| **Compiler**         | 源码 -> 目标文件 (Src -> Obj) | `g++` / `clang++`      | `cl.exe`      |
| **Linker**           | 目标文件 -> Exe (Obj -> Exe)  | `ld`                   | `link.exe`    |
| **Std Lib**          | 提供 vector, string 等        | `libstdc++` / `libc++` | `msvcprt.lib` |
| **Debugger**         | 调试 (Debug)                  | `gdb` / `lldb`         | VS Debugger   |
