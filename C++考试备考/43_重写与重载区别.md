## 题目 / Вопрос

- **中文**：函数“重写（覆盖，override）”与“重载（overload）”在语法和语义上有什么区别？  
- **俄文**: Чем отличается переопределение от перегрузки функции (синтаксис и семантика)?

这是 C++ 面试中最经典的问题之一。尽管名字相似，但它们属于完全不同的机制。

Это один из самых классических вопросов на собеседовании по C++. Несмотря на похожие названия, это совершенно разные механизмы.

------

### 1. 重载 / Перегрузка (Overloading)

**语义 / Семантика**:

- **中文**: 为了方便使用，允许在**同一个作用域**（通常是同一个类或全局作用域）中存在多个**同名函数**。编译器根据参数列表的不同来决定调用哪一个。这是**编译时多态**（静态绑定）。
- **Русский**: Для удобства использования разрешается существование нескольких функций с **одним и тем же именем** в **одной области видимости** (обычно в одном классе или глобально). Компилятор решает, какую из них вызвать, основываясь на списке параметров. Это **полиморфизм времени компиляции** (статическое связывание).

**语法规则 / Синтаксические правила**:

1. **作用域**: 必须在**同一作用域**。
2. **函数名**: 必须**相同**。
3. **参数**: 必须**不同**（个数、类型或顺序）。
4. **无关因素**: 返回值类型不同**不足以**构成重载。
5. **关键字**: 不需要 `virtual`。

**Правила**:

1. **Область**: Должны быть в **одной области видимости**.
2. **Имя**: Должно быть **одинаковым**.
3. **Параметры**: Должны **отличаться** (количеством, типом или порядком).
4. **Неважно**: Различия только в типе возвращаемого значения **недостаточно** для перегрузки.
5. **Ключевое слово**: `virtual` не требуется.

------

### 2. 重写 (覆盖) / Переопределение (Overriding)

**语义 / Семантика**:

- **中文**: 在**继承体系**中，派生类重新定义基类中已经存在的虚函数，以改变其行为。这是**运行时多态**（动态绑定）的基础。
- **Русский**: В **иерархии наследования** производный класс заново определяет виртуальную функцию, уже существующую в базовом классе, чтобы изменить её поведение. Это основа **полиморфизма времени выполнения** (динамическое связывание).

**语法规则 / Синтаксические правила**:

1. **作用域**: 分别位于**基类**和**派生类**。
2. **函数名**: 必须**相同**。
3. **参数与返回值**: 必须**完全相同**（协变返回类型除外）。
4. **必要条件**: 基类函数必须有 **`virtual`** 关键字。
5. **安全检查**: C++11 引入了 `override` 关键字来显式标记，防止拼写错误。

**Правила**:

1. **Область**: Находятся в **базовом** и **производном** классах соответственно.
2. **Имя**: Должно быть **одинаковым**.
3. **Параметры и возврат**: Должны быть **полностью идентичны** (за исключением ковариантных возвращаемых типов).
4. **Условие**: Функция базового класса должна иметь ключевое слово **`virtual`**.
5. **Безопасность**: C++11 ввел ключевое слово `override` для явной маркировки и предотвращения опечаток.

------

### 对比总结 / Сравнительная таблица

| **特征 / Характеристика**       | **重载 (Overload)**              | **重写 (Override)**                   |
| ------------------------------- | -------------------------------- | ------------------------------------- |
| **范围 / Область**              | 同一作用域 / Одна область        | 父类与子类之间 / Между Base и Derived |
| **参数 / Параметры**            | **必须不同** / Должны отличаться | **必须相同** / Должны совпадать       |
| **Virtual?**                    | 可选 (无关) / Необязательно      | **必须有** / Обязательно              |
| **绑定时间 / Время связывания** | 编译时 (Early Binding)           | 运行时 (Late Binding)                 |

### 代码示例 / Пример кода

C++

```c
#include <iostream>

class Base {
public:
    // 1. Overloading (in same class)
    // 重载：同名，参数不同
    void work(int i) { std::cout << "Base work(int)\n"; }
    void work(double d) { std::cout << "Base work(double)\n"; }

    // Virtual function intended for Overriding
    virtual void show() { std::cout << "Base Show\n"; }
};

class Derived : public Base {
public:
    // 2. Overriding (Inheritance + Virtual)
    // 重写：覆盖基类的行为
    // 'override' keyword (C++11) ensures safety
    void show() override { 
        std::cout << "Derived Show\n"; 
    }
};

int main() {
    Base b;
    Derived d;
    
    // --- Overloading Demo ---
    b.work(10);   // Calls work(int)
    b.work(3.14); // Calls work(double)

    // --- Overriding Demo ---
    Base* ptr = &d;
    // Runtime Polymorphism: Calls Derived::show() because of virtual/override
    // 运行时多态：调用 Derived::show()
    ptr->show(); 

    return 0;
}
```
