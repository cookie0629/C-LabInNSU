## 题目 / Вопрос

- **中文**：C++ 中有哪些方式定义枚举？每种枚举各有什么性质？各自适用于哪些场景？  
- **俄文**: Какие виды определения перечислений в C++ вы знаете? Какие свойства у каждого вида? Для чего используется каждый вид?

在 C++ 中，枚举主要分为两个“流派”：传统的 **不限域枚举 (Unscoped Enum)** 和 C++11 引入的更安全的 **限域枚举 (Scoped Enum / enum class)**。

以下是中俄互译的详细解答：

------

### 1. 不限域枚举 (Unscoped Enumeration / Неограниченное перечисление)

这是 C 语言风格的传统枚举。

(Это традиционное перечисление в стиле C.)

- **语法 (Синтаксис)**:

  C++

  ```
  enum Color { RED, GREEN, BLUE };
  ```

- **性质 (Свойства)**:

  1. **命名空间污染 (Namespace Pollution / Загрязнение пространства имен)**:
     - **中文**: 枚举成员（如 `RED`）会直接泄露到外部作用域。你不能在同一个作用域内的两个不同枚举中使用同名成员（例如 `TrafficLight::RED` 和 `Color::RED` 会冲突）。
     - **Русский**: Члены перечисления (например, `RED`) попадают прямо во внешнюю область видимости. Нельзя использовать одинаковые имена членов в двух разных перечислениях внутри одной области видимости (конфликт между `TrafficLight::RED` и `Color::RED`).
  2. **隐式转换 (Implicit Conversion / Неявное преобразование)**:
     - **中文**: 枚举值会自动、隐式地转换为整数（`int`）。这虽然方便，但容易导致逻辑错误（比如把 `Color::RED` 和 `TrafficLight::GREEN` 意外相加）。
     - **Русский**: Значения перечисления автоматически и неявно преобразуются в целые числа (`int`). Это удобно, но может привести к логическим ошибкам (например, случайное сложение `Color::RED` и `TrafficLight::GREEN`).

- **适用场景 (Сценарии использования)**:

  - 兼容旧代码 (Legacy Code)。
  - 作为简单的整数常量集合（替代 `#define`）。
  - 需要经常当作整数参与位运算（Bitwise operations）的标志位。

------

### 2. 限域枚举 (Scoped Enumeration / Перечисление с областью видимости)

这是 C++11 引入的现代化枚举，通常称为 enum class。

(Это современное перечисление, введенное в C++11, обычно называемое enum class.)

- **语法 (Синтаксис)**:

  C++

  ```
  enum class Color { RED, GREEN, BLUE };
  ```

- **性质 (Свойства)**:

  1. **作用域封闭 (Scoped / Ограниченная область видимости)**:
     - **中文**: 枚举成员仅在枚举内部可见。必须使用 `Color::RED` 访问，单纯写 `RED` 编译器无法识别。这彻底解决了命名冲突。
     - **Русский**: Члены перечисления видны только внутри перечисления. Доступ к ним возможен только через `Color::RED`, просто `RED` компилятор не поймет. Это полностью решает проблему конфликта имен.
  2. **强类型 (Strongly Typed / Строгая типизация)**:
     - **中文**: **不会**隐式转换为整数。如果你试图将 `Color::RED` 赋值给一个 `int`，或者将它与另一个枚举比较，编译器会报错。
     - **Русский**: **Не** преобразуется неявно в целое число. Если вы попытаетесь присвоить `Color::RED` переменной `int` или сравнить его с другим перечислением, компилятор выдаст ошибку.
  3. **指定底层类型 (Underlying Type / Базовый тип)**:
     - **中文**: 可以显式指定底层数据类型以节省内存（例如 `enum class Status : char { ... }`）。
     - **Русский**: Можно явно указать базовый тип данных для экономии памяти (например, `enum class Status : char { ... }`).

- **适用场景 (Сценарии использования)**:

  - **所有现代 C++ 开发的默认选择**。
  - 需要类型安全，防止误用的场景。
  - API 接口定义（因为其大小和类型是确定的）。

------

### 代码对比 (Сравнение в коде)

C++

```c
#include <iostream>

// 1. 传统枚举 (Classic)
enum TrafficLight { RED, YELLOW, GREEN };

// 2. 现代枚举 (Modern)
enum class Color { RED, YELLOW, GREEN }; 

int main() {
    // A. 作用域测试 (Scope Test)
    int x = RED;            // OK: TrafficLight::RED 泄露到了全局 (Leaked to global)
    // int y = Color::RED;  // Error! 必须写 Color::RED (Must use Color::RED)
    
    // B. 类型安全测试 (Type Safety Test)
    if (x == 0) {}          // OK: 隐式转换为 int (Implicit int conversion)
    
    Color c = Color::RED;
    // if (c == 0) {}       // Error! 无法与 int 比较 (Cannot compare with int)
    // if (c == RED) {}     // Error! 类型不匹配 (Type mismatch)
    
    if (c == Color::RED) {} // OK
    
    // 强制转换 (Explicit Cast)
    int val = static_cast<int>(c); // OK

    return 0;
}
```

### 总结 (Резюме)

| **特性 (Характеристика)**     | **enum (Unscoped)**                 | **enum class (Scoped)**       |
| ----------------------------- | ----------------------------------- | ----------------------------- |
| **名字冲突 (Name Conflict)**  | 容易发生 (High risk)                | **无 (None)**                 |
| **转换为整数 (To Integer)**   | 隐式 (Implicit)                     | **显式 (Explicit only)**      |
| **类型安全 (Safety)**         | 低 (Low)                            | **高 (High)**                 |
| **推荐程度 (Recommendation)** | 仅用于特殊位运算 (Use for bitmasks) | **默认推荐 (Default choice)** |
