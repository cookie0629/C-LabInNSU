## 题目 / Вопрос

- **中文**：C++ 中什么是“运算符重载”？它通常用于哪些目的？  
- **俄文**: Что такое перегрузка операторов в C++? Для каких целей она чаще всего используется?

**运算符重载（Operator Overloading）** 是 C++ 中的一项特性，允许开发者重新定义大多数内置运算符（如 `+`, `-`, `==`, `[]`, `<<`）在应用于**用户自定义类型**（类或结构体）时的行为。

**Перегрузка операторов (Operator Overloading)** — это возможность C++, позволяющая разработчикам переопределять поведение большинства встроенных операторов (например, `+`, `-`, `==`, `[]`, `<<`) при их применении к **пользовательским типам данных** (классам или структурам).

------

### 1. 核心概念 / Основная концепция

- **中文**: 它本质上是**函数重载**的一种特殊形式。当你写 `obj1 + obj2` 时，编译器会将其转换为对名为 `operator+` 的函数的调用。
  - 它让自定义类用起来像内置类型（如 `int`）一样自然。
  - *注意*: 你不能创建新的运算符（如 `**`），也不能改变运算符的优先级。
- **Русский**: По сути, это специальная форма **перегрузки функций**. Когда вы пишете `obj1 + obj2`, компилятор преобразует это в вызов функции с именем `operator+`.
  - Это позволяет работать с классами так же естественно, как со встроенными типами (например, `int`).
  - *Важно*: Нельзя создавать новые операторы (например, `**`) или менять приоритет операторов.

------

### 2. 主要用途 / Основные цели использования

#### **A. 数学运算 (Linear Algebra & Math)**

- **中文**: 用于复数、矩阵、向量等数学类。
  - *例*: `Vector v3 = v1 + v2;` 比 `Vector v3 = v1.add(v2);` 更直观。
- **Русский**: Для математических классов (комплексные числа, матрицы, векторы).
  - *Пример*: `Vector v3 = v1 + v2;` намного нагляднее, чем `Vector v3 = v1.add(v2);`.

#### **B. 输入/输出 (I/O Integration)**

- **中文**: 重载 `<<` 和 `>>` 以支持 `std::cout` 和 `std::cin`。
  - *例*: `std::cout << myObject;`
- **Русский**: Перегрузка `<<` и `>>` для поддержки `std::cout` и `std::cin`.
  - *Пример*: `std::cout << myObject;`

#### **C. 容器访问与迭代 (Containers & Iteration)**

- **中文**: 模拟数组或指针的行为。
  - `operator[]`: 让类像数组一样访问元素（如 `std::vector`, `std::map`）。
  - `operator*` 和 `operator->`: 让类像指针一样工作（如智能指针、迭代器）。
- **Русский**: Имитация поведения массивов или указателей.
  - `operator[]`: Доступ к элементам как в массиве (как в `std::vector`, `std::map`).
  - `operator*` и `operator->`: Работают как указатели (умные указатели, итераторы).

#### **D. 比较与排序 (Comparison & Sorting)**

- **中文**: 重载 `==`, `<`, `!=` 等。这对于将对象放入 `std::set` 或作为 `std::map` 的键至关重要。
- **Русский**: Перегрузка `==`, `<`, `!=` и т.д. Это критически важно для помещения объектов в `std::set` или использования в качестве ключей в `std::map`.

------

### 代码示例 / Пример кода

C++

```c
#include <iostream>

class Point {
private:
    int x, y;

public:
    Point(int x = 0, int y = 0) : x(x), y(y) {}

    // 1. Math: Vector Addition
    // 数学运算：向量加法
    Point operator+(const Point& other) const {
        return Point(x + other.x, y + other.y);
    }

    // 2. Comparison: Equality
    // 比较：相等性检查
    bool operator==(const Point& other) const {
        return x == other.x && y == other.y;
    }

    // 3. I/O: Output (Must be a friend or non-member)
    // 输入输出：输出（必须是友元或非成员函数）
    friend std::ostream& operator<<(std::ostream& os, const Point& p) {
        os << "(" << p.x << ", " << p.y << ")";
        return os;
    }
};

int main() {
    Point p1(1, 2);
    Point p2(3, 4);

    Point p3 = p1 + p2; // Calls operator+
    
    if (p1 == p2) {     // Calls operator==
        std::cout << "Equal";
    }

    std::cout << p3 << std::endl; // Calls operator<<, Output: (4, 6)
    
    return 0;
}
```
