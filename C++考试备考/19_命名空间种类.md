## 题目 / Вопрос

- **中文**：C++ 中有哪些类型的命名空间（`namespace`）？它们用于什么目的？  
- **俄文**: Какие бывают пространства имён в C++ и для чего они используются?

在 C++ 中，命名空间主要用于**防止命名冲突 (Name Collisions)** 并组织代码结构。除了最普通的命名空间外，还有几种特殊的变体，每种都有其特定的架构目的。

以下是中俄互译的详细分类：

------

### 1. 具名命名空间 (Named Namespace / Именованное пространство)

这是最常见的形式。

(Это самая распространенная форма.)

- **Syntax**: `namespace MyLib { ... }`
- **中文**：
  - 用于将相关的类、函数和变量逻辑上组合在一起。
  - **目的**：避免库与库之间，或者库与用户代码之间的名字冲突。
- **Русский**：
  - Используется для логической группировки связанных классов, функций и переменных.
  - **Цель**: Избежать конфликтов имен между библиотеками или между библиотекой и пользовательским кодом.

------

### 2. 匿名/无名命名空间 (Unnamed/Anonymous Namespace / Безымянное пространство)

这是现代 C++ 中替代 static 全局变量的首选方式。

(Это предпочтительный способ замены глобальных static переменных в современном C++.)

- **Syntax**: `namespace { ... }`
- **中文**：
  - 其中的成员具有 **内部链接性 (Internal Linkage)**。
  - **目的**：使其中的变量或函数**仅在当前源文件 (.cpp) 内可见**，而在其他文件中不可见。这有助于避免“全局命名空间污染”。
- **Русский**：
  - Члены этого пространства имеют **внутреннее связывание (Internal Linkage)**.
  - **Цель**: Сделать переменные или функции видимыми **только в текущем исходном файле (.cpp)** и невидимыми для других. Это помогает избежать «загрязнения глобального пространства имен».

------

### 3. 全局命名空间 (Global Namespace / Глобальное пространство)

- **Syntax**: (无显式定义 / Без явного определения)
- **中文**：
  - 所有没有被包含在任何命名空间中的代码都在这里。`main()` 函数总是位于全局命名空间。
  - 可以使用作用域解析运算符 `::member` 显式访问全局变量。
- **Русский**：
  - Весь код, не заключенный ни в какое пространство имен, находится здесь. Функция `main()` всегда находится в глобальном пространстве.
  - Можно явно обратиться к глобальной переменной с помощью оператора разрешения области видимости `::member`.

------

### 4. 内联命名空间 (Inline Namespace / Инлайн-пространство)

这是 C++11 引入的高级特性，主要用于库的 版本控制 (Versioning)。

(Это продвинутая функция, введенная в C++11, в основном для версионирования (Versioning) библиотек.)

- **Syntax**: `inline namespace V2 { ... }`
- **中文**：
  - 内联命名空间中的成员会被**自动提升**到父命名空间中。使用者不需要写出子命名空间的名字就能直接访问成员。
  - **目的**：允许库作者在不破坏现有代码的情况下更新库版本（ABI 兼容性）。例如，默认使用 `V2` 版本，但仍然保留 `V1` 以供旧代码链接。
- **Русский**：
  - Члены инлайн-пространства **автоматически поднимаются** в родительское пространство имен. Пользователям не нужно писать имя вложенного пространства для доступа к ним.
  - **Цель**: Позволить авторам библиотек обновлять версии без поломки существующего кода (совместимость ABI). Например, использовать `V2` по умолчанию, но сохранить `V1` для линковки старого кода.

**内联命名空间**就像是给代码库的不同版本加上一个"透明包装纸"：新版代码可以**直接访问**，旧版代码也能**兼容使用**。

想象一个图书馆管理不同版本的书籍：

cpp

```c
// 传统命名空间（图书馆的书架分开摆放）
namespace Library {
    namespace v1 {  // v1 书架
        void oldBook() { /* 第一版 */ }
    }
    
    namespace v2 {  // v2 书架
        void newBook() { /* 第二版 */ }
    }
}

// 读者需要指定版本
Library::v1::oldBook();  // 去 v1 书架找
Library::v2::newBook();  // 去 v2 书架找
```



cpp

```c
// 内联命名空间（最新版摆在最外面）
namespace Library {
    inline namespace v2 {  // v2 放在最显眼位置
        void newBook() { /* 第二版 */ }
    }
    
    namespace v1 {  // v1 还在，但需要特别指定
        void oldBook() { /* 第一版 */ }
    }
}

// 读者访问方式
Library::newBook();     // 直接拿到最新版（v2）
Library::v1::oldBook(); // 也能找到旧版
```



------

### 5. 嵌套命名空间 (Nested Namespace / Вложенное пространство)

- **Syntax**: `namespace A { namespace B { ... } }` or `namespace A::B { ... }` (C++17)
- **中文**：
  - 用于构建层次化的代码结构。
  - **目的**：模块化管理大型项目（例如 `std::chrono`）。
- **Русский**：
  - Используется для построения иерархической структуры кода.
  - **Цель**: Модульное управление большими проектами (например, `std::chrono`).

------

### 代码示例 (Пример кода)

C++

```c
#include <iostream>

// 1. 全局变量 (Глобальная переменная)
int val = 100;

// 2. 具名命名空间 (Именованное пространство)
namespace MyLib {
    int val = 200;

    // 4. 内联命名空间 (Инлайн-пространство)
    // 用户可以直接访问 MyLib::func()，它默认指向 V2::func
    // (Пользователь может вызвать MyLib::func(), это V2::func по умолчанию)
    inline namespace V2 {
        void func() { std::cout << "Version 2 function\n"; }
    }
    
    namespace V1 {
        void func() { std::cout << "Version 1 function\n"; }
    }
}

// 3. 匿名命名空间 (Безымянное пространство)
namespace {
    // 只有本文件能看到这个变量，相当于 static int internalVar
    // (Только этот файл видит эту переменную, аналог static int)
    int internalVar = 300; 
}

int main() {
    int val = 50; // 局部变量 (Локальная переменная)

    std::cout << val;           // 50 (Local)
    std::cout << ::val;         // 100 (Global)
    std::cout << MyLib::val;    // 200 (Named)
    std::cout << internalVar;   // 300 (Anonymous)
    
    MyLib::func();      // Calls V2::func (Inline)
    MyLib::V1::func();  // Calls V1::func (Explicit)

    return 0;
}
```

### 总结 (Резюме)

| **类型 (Тип)** | **关键字 (Ключевое слово)** | **主要目的 (Главная цель)**                    |
| -------------- | --------------------------- | ---------------------------------------------- |
| **Named**      | `namespace N`               | 代码组织与防冲突 (Организация и защита имен)   |
| **Anonymous**  | `namespace`                 | 文件内私有/内部链接 (Приватность внутри файла) |
| **Inline**     | `inline namespace`          | 版本控制/ABI 演化 (Версионирование/ABI)        |
| **Nested**     | `namespace A::B`            | 层次化结构 (Иерархия)                          |
