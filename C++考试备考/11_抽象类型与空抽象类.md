## 题目 / Вопрос

- **中文**：在 C++ 中如何定义抽象的用户自定义类型？什么是“空抽象类”惯用法？  
- **俄文**：Как в C++ определяется абстрактный пользовательский тип данных? Что такое идиома пустого абстрактного класса?

在 C++ 中，并没有像 Java 或 C# 那样专门的 `interface` 关键字。抽象类型和接口是通过特定的类设计模式来实现的。

以下是中俄互译的详细解答：

------

### 一、 如何定义抽象类型？ (Как определить абстрактный тип?)

在 C++ 中，抽象类 (Abstract Class) 是指不能被实例化的类。要定义一个抽象类型，必须满足以下条件：

(В C++ абстрактный класс (Abstract Class) — это класс, который нельзя инстанцировать. Для определения абстрактного типа должны быть соблюдены следующие условия:)

1. **纯虚函数 (Pure Virtual Function / Чисто виртуальная функция)**
   - **中文**：类中必须包含至少一个纯虚函数。语法是在函数声明后加上 `= 0`。
   - **Русский**：Класс должен содержать как минимум одну чисто виртуальную функцию. Синтаксис: добавление `= 0` после объявления функции.
2. **虚析构函数 (Virtual Destructor / Виртуальный деструктор)**
   - **中文**：作为基类，抽象类通常应该提供一个虚析构函数（即使是空的），以确保通过基类指针删除对象时能正确调用子类的析构函数。
   - **Русский**：Как базовый класс, абстрактный класс обычно должен предоставлять виртуальный деструктор (даже если он пуст), чтобы гарантировать правильный вызов деструктора производного класса при удалении объекта через указатель на базовый класс.

------

### 二、 “空抽象类”惯用法 (Идиома пустого абстрактного класса)

这通常被称为 接口类 (Interface Class)。

(Это обычно называется классом-интерфейсом (Interface Class).)

- **定义 (Определение)**：
  - **中文**：一个没有任何数据成员（无状态），只有纯虚函数和虚析构函数的类。
  - **Русский**：Класс, который не имеет членов данных (без состояния) и содержит только чисто виртуальные функции и виртуальный деструктор.
- **作用 (Роль)**：
  - **中文**：它相当于 Java 或 C# 中的 `interface`。它定义了一组行为规范（协议），而不提供任何实现细节。它允许 C++ 安全地实现 **多重继承**（即继承多个接口），因为没有数据成员，就不会出现“菱形继承”导致的数据冗余问题。
  - **Русский**：Это эквивалент `interface` в Java или C#. Он определяет набор поведенческих спецификаций (протокол) без предоставления деталей реализации. Это позволяет безопасно реализовать **множественное наследование** в C++ (наследование нескольких интерфейсов), так как отсутствие членов данных исключает проблемы избыточности данных, возникающие при «ромбовидном наследовании».

------

### 三、 代码示例 (Пример кода)

C++

```
#include <iostream>
#include <vector>

// 1. 定义抽象类型 (也就是“空抽象类”惯用法 / 接口)
// 1. Определение абстрактного типа (Идиома интерфейса)
class IDrawable {
public:
    // 纯虚函数 (Pure Virtual Function)
    virtual void draw() const = 0; 

    // 虚析构函数 (Virtual Destructor)
    virtual ~IDrawable() = default;
};

// 2. 实现接口 (Реализация интерфейса)
class Circle : public IDrawable {
public:
    void draw() const override {
        std::cout << "Drawing a Circle" << std::endl;
    }
};

class Square : public IDrawable {
public:
    void draw() const override {
        std::cout << "Drawing a Square" << std::endl;
    }
};

// 3. 多态使用 (Полиморфное использование)
void renderScene(const std::vector<IDrawable*>& objects) {
    for (const auto* obj : objects) {
        obj->draw(); // 动态绑定 (Dynamic Binding)
    }
}

int main() {
    Circle c;
    Square s;
    
    // IDrawable item; // 错误！无法实例化抽象类
    // Ошибка! Нельзя создать экземпляр абстрактного класса
    
    std::vector<IDrawable*> scene = { &c, &s };
    renderScene(scene);
    
    return 0;
}
```

### 总结 (Резюме)

| **特性 (Характеристика)**           | **普通抽象类 (Abstract Class)**                          | **空抽象类/接口 (Interface)**              |
| ----------------------------------- | -------------------------------------------------------- | ------------------------------------------ |
| **纯虚函数** `(= 0)`                | 至少有一个 (Хотя бы одна)                                | **全部都是** (Все функции)                 |
| **数据成员** (Data Members)         | 可以有 (Могут быть)                                      | **没有** (Отсутствуют)                     |
| **目的** (Цель)                     | 代码复用 + 接口定义 (Переиспользование кода + Интерфейс) | 纯粹的契约/协议 (Чистый контракт/Протокол) |
| **多重继承** (Multiple Inheritance) | 危险 (Опасно)                                            | **安全且推荐** (Безопасно и рекомендуется) |
