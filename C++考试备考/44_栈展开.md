## 题目 / Вопрос

- **中文**：所谓“栈展开（stack unwinding）”过程表示的是什么？  
- **俄文**: Что выражает процесс «раскрутки стека»?

**栈展开（Stack Unwinding）** 是 C++ 异常处理机制的核心组成部分。

**Раскрутка стека (Stack Unwinding)** — это ключевой компонент механизма обработки исключений в C++.

### 1. 核心定义 / Основное определение

- **中文**: 当程序抛出异常（`throw`）时，系统需要寻找匹配的 `catch` 块。如果当前函数没有处理该异常，程序会**立刻退出当前函数**，返回到调用者，并在调用者中继续寻找。这个**逐层退出函数调用栈**的过程，就叫栈展开。
- **Русский**: Когда программа выбрасывает исключение (`throw`), система должна найти соответствующий блок `catch`. Если текущая функция не обрабатывает исключение, программа **немедленно выходит из текущей функции**, возвращается к вызывающей и продолжает поиск там. Этот процесс **послойного выхода из стека вызовов** и называется раскруткой стека.

------

### 2. 关键行为：自动析构 / Ключевое поведение: Автоматическая деструкция

这是栈展开最重要的特性，也是 C++ RAII（资源获取即初始化）的基础。

Это самая важная особенность раскрутки стека и основа идиомы RAII в C++.

- **中文**: 在栈展开过程中，随着函数栈帧被弹出，该作用域内所有**已经成功构造**的局部对象（栈对象），其**析构函数**会被自动调用。
  - *作用*: 这确保了即使发生异常，资源（内存、文件锁等）也能被正确释放。
- **Русский**: В процессе раскрутки стека, по мере удаления кадров стека, автоматически вызываются **деструкторы** всех локальных объектов (объектов стека), которые были **успешно сконструированы** в этой области видимости.
  - *Роль*: Это гарантирует, что ресурсы (память, файловые блокировки и т.д.) будут корректно освобождены даже при возникновении исключения.

------

### 3. 过程步骤 / Этапы процесса

1. **Throw**: 异常在某行代码被抛出。
2. **Scan**: 运行时系统检查当前 try-catch 块。
3. **Unwind (Loop)**:
   - 如果没有找到匹配的 catch，**销毁**当前栈帧中的局部对象（调用析构函数）。
   - **弹出**当前栈帧，返回上一级调用函数。
4. **Catch**: 找到匹配的 catch 块，停止展开，控制权交给该处理块。
5. **Terminate**: 如果退到了 `main` 函数依然没找到 catch，程序调用 `std::terminate()` 崩溃。

------

### 代码演示 / Демонстрация кода

C++

```c
#include <iostream>
#include <stdexcept>

class Worker {
    std::string name;
public:
    Worker(std::string n) : name(n) { 
        std::cout << "Constructing: " << name << std::endl; 
    }
    ~Worker() { 
        // 这里的代码会在栈展开时执行
        // Этот код выполнится при раскрутке стека
        std::cout << "Destructing: " << name << std::endl; 
    }
};

void dangerousFunction() {
    Worker w1("Inner"); // 局部对象 / Локальный объект
    std::cout << "About to throw exception..." << std::endl;
    throw std::runtime_error("Error occurred!");
    
    // 这行永远不会执行
    // Эта строка никогда не выполнится
    std::cout << "This will be skipped." << std::endl; 
}

int main() {
    try {
        Worker w2("Outer");
        dangerousFunction();
    } catch (const std::exception& e) {
        std::cout << "Caught exception: " << e.what() << std::endl;
    }
    return 0;
}
```

**输出结果 / Результат вывода:**

Plaintext

```
Constructing: Outer
Constructing: Inner
About to throw exception...
Destructing: Inner   <-- Stack Unwinding happened here! (栈展开发生在这里!)
Destructing: Outer   <-- Stack Unwinding continues (继续展开)
Caught exception: Error occurred!
```
