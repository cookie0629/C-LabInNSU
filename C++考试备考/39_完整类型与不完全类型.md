## 题目 / Вопрос

- **中文**：在 C++ 中，一个类型在什么情况下被认为是“完全类型”（完整类型）？哪一种类型在 C++ 中总是“不完全类型”？  
- **俄文**: Когда тип в C++ является полным? Какой тип в C++ всегда является неполным?

在 C++ 中，类型的“完整性”决定了编译器能对该类型执行哪些操作。

В C++ «полнота» типа определяет, какие операции компилятор может выполнять с этим типом.

------

### 1. 什么是完全类型？/ Что такое полный тип?

- **中文定义**: 当编译器能够确定该类型的**大小（Size）**和**内存布局（Layout）**时，该类型被认为是“完全类型”。
  - 这意味着你可以：创建该类型的实例、计算 `sizeof`、访问其成员变量或方法。
  - **例子**: 基本类型 (`int`, `float`)，以及**定义体已结束**的类（即编译器已经看到了右大括号 `}`）。
- **Русское определение**: Тип считается полным, когда компилятор знает его **размер (Size)** и **размещение в памяти (Layout)**.
  - Это значит, что вы можете: создавать экземпляры, вычислять `sizeof`, обращаться к членам или методам.
  - **Примеры**: Фундаментальные типы (`int`, `float`) и классы, **определение которых завершено** (компилятор увидел закрывающую скобку `}`).

### 2. 哪种类型总是“不完全”的？/ Какой тип всегда «неполный»?

- **中文**: **`void` 类型**。
  - `void` 被 C++ 标准定义为一种特殊的、永远不完全的类型。你永远不能创建 `void` 类型的对象（如 `void v;` 是非法的），因为编译器不知道它需要多少内存。
- **Русский**: **Тип `void`**.
  - Стандарт C++ определяет `void` как особый, всегда неполный тип. Вы никогда не сможете создать объект типа `void` (например, `void v;` — ошибка), так как компилятор не знает, сколько памяти для него требуется.

------

### 3. 常见的不完全类型场景 / Частые сценарии неполных типов

除了 void，还有一种常见的情况是前置声明（Forward Declaration）。

Помимо void, распространенным случаем является предварительное объявление (Forward Declaration).

- **数组**: `int arr[];` (未知大小 / неизвестный размер).
- **类**: `class MyClass;` (只声明了名字，未定义内容 / объявлено имя, но нет тела).

#### 规则 / Правила:

| **操作 / Операция**              | **完全类型 (Complete)** | **不完全类型 (Incomplete)** |
| -------------------------------- | ----------------------- | --------------------------- |
| 定义变量 / Определить переменную | ✅ OK                    | ❌ Error                     |
| 定义指针/引用 / Указатель/Ссылка | ✅ OK                    | ✅ OK (`class X* p;`)        |
| `sizeof`                         | ✅ OK                    | ❌ Error                     |
| 访问成员 / Доступ к членам       | ✅ OK                    | ❌ Error                     |

------

### 代码示例 / Пример кода

C++

```c
#include <iostream>

// 1. Incomplete Type (Forward Declaration)
// 不完全类型（前置声明）
class Target; 

// 2. Always Incomplete Type
// 总是非完全类型
// void variable; // Error: variable has incomplete type 'void'

class Owner {
    // ✅ OK: 可以持有不完全类型的指针
    // ✅ OK: Можно хранить указатель на неполный тип
    Target* ptr; 
    
    // ❌ Error: 不能持有不完全类型的实例
    // ❌ Error: Нельзя хранить экземпляр неполного типа
    // Target obj; 
};

// Now we define the class -> It becomes Complete
// 现在定义类 -> 它变成了完全类型
class Target {
    int id;
};

int main() {
    Target t; // ✅ OK: Target is now complete
    std::cout << sizeof(t) << std::endl; // ✅ OK
    return 0;
}
```
