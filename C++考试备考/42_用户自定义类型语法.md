## 题目 / Вопрос

- **中文**：请描述在 C++ 中声明用户自定义类型时，语法上的主要特性。  
- **俄文**: Опишите основные особенности синтаксиса объявления пользовательского типа данных в C++?

在 C++ 中声明用户自定义类型（User-Defined Types, UDTs）时，主要涉及类（class）、结构体（struct）、联合体（union）和枚举（enum）。其语法有几个显著的特性和规则。

При объявлении пользовательских типов данных (UDT) в C++, в основном используются классы (`class`), структуры (`struct`), объединения (`union`) и перечисления (`enum`). Синтаксис имеет несколько отличительных особенностей и правил.

------

### 1. 结尾分号陷阱 / Ловушка с точкой с запятой (The Semicolon)

- **中文**: 这是 C++ 语法中最容易被遗忘的规则。所有的类型定义（`class`, `struct`, `enum`, `union`）必须**以分号 `;` 结尾**。
  - *原因*: 历史遗留问题，允许在定义类型后立即声明该类型的变量实例（如 `struct A { ... } variable;`）。
- **Русский**: Это правило, которое чаще всего забывают. Все определения типов (`class`, `struct`, `enum`, `union`) должны **заканчиваться точкой с запятой `;`**.
  - *Причина*: Историческое наследие, позволяющее объявлять переменную этого типа сразу после определения (например, `struct A { ... } variable;`).

### 2. 访问控制块 / Блоки контроля доступа (Access Specifiers)

- **中文**: C++ 不像 Java 那样在每个变量前写 `public`。它使用**标签块**（`public:`, `private:`, `protected:`）来成批设置成员的访问权限。
  - *默认权限*: `class` 默认为 `private`，`struct` 默认为 `public`。
- **Русский**: В отличие от Java, где `public` пишется перед каждой переменной, C++ использует **блоки меток** (`public:`, `private:`, `protected:`) для групповой настройки доступа.
  - *По умолчанию*: В `class` — `private`, в `struct` — `public`.

### 3. 就地初始化 / Инициализация по месту (In-class Initializers) (C++11)

- **中文**: 现代 C++ 允许直接在类声明中给成员变量赋初值。这被称为“默认成员初始化器”。
- **Русский**: Современный C++ позволяет присваивать начальные значения переменным-членам прямо в объявлении класса. Это называется «инициализаторы членов по умолчанию».

### 4. 强类型枚举 / Строго типизированные перечисления (`enum class`)

- **中文**: C++11 引入了 `enum class`。与传统的 C 风格 `enum` 不同，它的成员不会泄漏到外部作用域，且不能隐式转换为整数。
- **Русский**: C++11 ввел `enum class`. В отличие от традиционного `enum` в стиле C, его члены не «утекают» во внешнюю область видимости и не преобразуются неявно в целые числа.

### 代码示例 / Пример кода

C++

```c
#include <iostream>

// 1. Enum Class (Strongly Typed) / Строгое перечисление
enum class Color : int {
    Red, 
    Green, 
    Blue
}; // <--- Semicolon is mandatory! / Точка с запятой обязательна!

// 2. Class Declaration / Объявление класса
class Widget {
// Access specifier label / Метка доступа
private: 
    // 3. In-class initialization / Инициализация по месту
    int id = 0; 
    double width = 10.5;

public:
    // Constructor / Конструктор
    Widget(int i) : id(i) {}

    void draw() {
        // 使用枚举时必须带作用域 / Нужно указывать область видимости enum
        Color c = Color::Red; 
    }
}; // <--- Don't forget this! / Не забудьте это!

int main() {
    Widget w(1);
    return 0;
}
```
