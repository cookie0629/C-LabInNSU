## 题目 / Вопрос

- **中文**：在 C 或 C++ 中，你知道哪些复合数据类型？它们各有什么性质？  
- **俄文**: Какие составные типы данных, определённые в C или в C++, вы знаете? Каковы их свойства?

以下是 C 和 C++ 中常见的复合数据类型（Compound Data Types），按 C 语言基础和 C++ 扩展特性分类。

Ниже представлены распространенные составные типы данных в C и C++, классифицированные по основам C и расширенным возможностям C++.

------

### 1. C & C++ 通用类型 / Общие типы для C и C++

这些类型在 C 语言中定义，在 C++ 中完全兼容。

Эти типы определены в C и полностью совместимы с C++.

#### **A. 数组 / Массив (Array)**

- **性质 (CN)**: 存储**相同类型**元素的集合。内存是连续分配的，大小在声明时固定（C99 变长数组除外）。
- **Свойства (RU)**: Коллекция элементов **одного типа**. Память выделяется непрерывно, размер фиксируется при объявлении (за исключением VLA в C99).

#### **B. 结构体 / Структура (Struct)**

- **性质 (CN)**: 将**不同类型**的数据组合在一起。成员在内存中按声明顺序排列（可能存在内存对齐填充）。在 C 中仅包含数据；在 C++ 中可以包含函数（类似类）。
- **Свойства (RU)**: Объединяет данные **разных типов**. Члены располагаются в памяти в порядке объявления (возможно выравнивание памяти). В C содержит только данные; в C++ может содержать функции (как класс).

#### **C. 联合体 / Объединение (Union)**

- **性质 (CN)**: 所有成员**共享同一块内存**。它的大小等于最大成员的大小。同一时间只能存储其中一个成员的值。主要用于节省内存或进行底层数据类型转换。
- **Свойства (RU)**: Все члены **разделяют одну и ту же область памяти**. Размер равен размеру самого большого члена. В один момент времени может хранить значение только одного члена. Используется для экономии памяти или низкоуровневого преобразования типов.

------

### 2. C++ 专属类型 / Типы, специфичные для C++

#### **D. 类 / Класс (Class)**

- **性质 (CN)**: 面向对象编程的核心。与 `struct` 类似，但默认访问权限是 `private`（私有）。支持**封装、继承和多态**。
- **Свойства (RU)**: Основа объектно-ориентированного программирования. Похож на `struct`, но доступ по умолчанию — `private` (частный). Поддерживает **инкапсуляцию, наследование и полиморфизм**.

#### **E. `std::pair` & `std::tuple` (Standard Library)**

- **性质 (CN)**: 现代 C++ 模板类型。`pair` 组合两个值，`tuple` 可以组合任意数量的值。
- **Свойства (RU)**: Шаблонные типы современного C++. `pair` объединяет два значения, `tuple` может объединять произвольное количество значений.

### 代码示例 / Пример кода

C++

```c
#include <iostream>
#include <vector>
#include <tuple>

// 1. Struct (C & C++)
// 定义一个包含不同数据的结构体
// Определение структуры с разными данными
struct Student {
    int id;
    float gpa;
};

// 2. Union (C & C++)
// 内存共享示例
// Пример разделения памяти
union DataConverter {
    int i;
    float f;
};

// 3. Class (C++ only features)
// 包含私有数据和方法的类
// Класс с приватными данными и методами
class Course {
private:
    std::string name;
public:
    void setName(std::string n) { name = n; }
    void printName() { std::cout << "Course: " << name << std::endl; }
};

int main() {
    // Array / Массив
    int numbers[3] = {1, 2, 3}; 

    // Struct Usage
    Student s1 = {101, 3.8};
    std::cout << "Student ID: " << s1.id << std::endl;

    // Union Usage
    DataConverter data;
    data.f = 3.14; 
    // 注意：此时读取 data.i 会得到 float 的二进制表示
    // Примечание: чтение data.i даст битовое представление float
    
    // Class Usage
    Course c;
    c.setName("Materials Science");
    c.printName();

    // C++17 Structured Binding with Tuple
    // 使用元组和结构化绑定
    std::tuple<int, double, char> myTuple = {10, 2.5, 'A'};
    auto [x, y, z] = myTuple; // Unpack tuple
    
    return 0;
}
```

### 关键区别总结 / Краткое сравнение

| **类型 / Тип** | **内存布局 / Память**          | **用途 / Назначение**       | **C vs C++**              |
| -------------- | ------------------------------ | --------------------------- | ------------------------- |
| **Array**      | 连续 / Непрерывная             | 简单列表 / Простые списки   | C++ 推荐 `std::vector`    |
| **Struct**     | 顺序排列 / Последовательная    | 数据记录 / Записи данных    | C++ 中可含方法            |
| **Union**      | 重叠 (共享) / Перекрывающаяся  | 变体数据 / Варианты данных  | C++17 推荐 `std::variant` |
| **Class**      | 顺序 (一般) / Последовательная | 对象模型 / Объектная модель | C++ 独有 (OOP)            |
