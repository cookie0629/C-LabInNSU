## 题目 / Вопрос

- **中文**：在 C++ 中，子类化（继承）多态是依靠哪三个要素实现的？这三个要素各自起到什么作用？  
- **俄文**：Благодаря каким трём элементам реализуется полиморфизм сабклассирования в C++? Какой вклад вносит каждый из трёх элементов?

------

### C++ 多态实现的三个要素

### Три элемента реализации полиморфизма в C++

在 C++ 中，实现动态多态（Dynamic Polymorphism）必须同时满足以下三个条件：

В C++ для реализации динамического полиморфизма необходимо одновременное выполнение следующих трех условий:

#### 1. 继承 (Inheritance) / Наследование

- **中文解释**：存在继承关系，即子类（Derived Class）必须继承自父类（Base Class）。通常是公有继承。
- **Русское объяснение**：Наличие отношений наследования: производный класс (Derived Class) должен наследовать от базового класса (Base Class). Обычно используется открытое (public) наследование.
- **作用 (Role / Роль)**：
  - **CN**: 建立了“是一个 (is-a)”的关系，使得子类对象可以被视为父类类型。
  - **RU**: Устанавливает отношение «является» (is-a), позволяя рассматривать объект производного класса как объект базового типа.

#### 2. 虚函数重写 (Virtual Function Overriding) / Переопределение виртуальных функций

- **中文解释**：父类中对应的函数必须声明为 `virtual`（虚函数），且子类必须重写（Override）该函数。
- **Русское объяснение**：Соответствующая функция в базовом классе должна быть объявлена как `virtual` (виртуальная), и производный класс должен переопределить (Override) эту функцию.
- **作用 (Role / Роль)**：
  - **CN**: 告诉编译器不要在编译时进行静态绑定，而是为该函数启用动态绑定机制（通过虚函数表 vtable）。
  - **RU**: Сообщает компилятору не выполнять статическое связывание во время компиляции, а включить механизм динамического связывания (через таблицу виртуальных функций vtable) для этой функции.

#### 3. 基类指针或引用 (Base Class Pointer or Reference) / Указатель или ссылка на базовый класс

- **中文解释**：必须通过基类的指针或引用，指向（或引用）子类的对象，并调用虚函数。
- **Русское объяснение**：Вызов виртуальной функции должен осуществляться через указатель или ссылку на базовый класс, который указывает (или ссылается) на объект производного класса.
- **作用 (Role / Роль)**：
  - **CN**: 触发多态行为的接口。虽然指针类型是基类，但实际执行的是该指针指向的具体对象（子类）的函数版本。
  - **RU**: Интерфейс, запускающий полиморфное поведение. Хотя тип указателя является базовым, фактически выполняется версия функции того конкретного объекта (производного класса), на который указывает этот указатель.

### 代码示例 / Пример кода

为了更直观地理解，请看下面的代码示例：

Для наглядности рассмотрите следующий пример кода:

C++

```
#include <iostream>

// 1. 继承 (Inheritance / Наследование)
class Shape {
public:
    // 2. 虚函数 (Virtual Function / Виртуальная функция)
    virtual void draw() {
        std::cout << "Drawing generic shape" << std::endl;
    }
};

class Circle : public Shape {
public:
    // 2. 重写 (Overriding / Переопределение)
    void draw() override {
        std::cout << "Drawing a Circle" << std::endl;
    }
};

int main() {
    Circle circle;
    
    // 3. 基类指针指向子类对象 
    // (Base class pointer pointing to derived object / 
    //  Указатель на базовый класс, указывающий на объект производного класса)
    Shape* shapePtr = &circle;

    // 调用 (Call / Вызов)
    shapePtr->draw(); // Output: Drawing a Circle

    return 0;
}
```

### 总结 / Резюме

- 没有继承，就没有层级关系。

  (Без наследования нет иерархии.)

- 没有虚函数，编译器只会根据指针类型（基类）调用函数（静态绑定）。

  (Без виртуальных функций компилятор будет вызывать функцию, основываясь только на типе указателя (статическое связывание).)

- 没有基类指针/引用，就无法在运行时统一处理不同类型的对象。

  (Без указателя/ссылки на базовый класс невозможно единообразно обрабатывать объекты разных типов во время выполнения.)
