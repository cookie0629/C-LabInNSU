## 题目 / Вопрос

- **中文**：C++ 语言的语法由哪些基本元素构成？  
- **俄文**: Какие элементы составляют синтаксис языка C++?

C++ 的语法结构可以被视为由不同层次的“积木”搭建而成。从最微小的词法单元到宏大的程序结构，主要包含以下基本元素。

Синтаксис C++ можно рассматривать как конструкцию, построенную из "кирпичиков" разных уровней. От мельчайших лексических единиц до крупных программных структур, он состоит из следующих базовых элементов.

------

### 1. 词法记号 (Tokens) / Лексические единицы (Токены)

这是编译器能理解的最小单元。

Это мельчайшие единицы, которые понимает компилятор.

- **关键字 / Ключевые слова (Keywords)**:
  - 语言保留的具有特殊意义的单词，如 `int`, `return`, `class`, `if`, `namespace`。
  - Зарезервированные языком слова с особым значением.
- **标识符 / Идентификаторы (Identifiers)**:
  - 程序员给变量、函数、类命的名。规则：字母、数字、下划线组成，不能以数字开头。
  - Имена, которые программист дает переменным, функциям и классам. Правило: буквы, цифры, подчеркивания; не может начинаться с цифры.
- **字面量 / Литералы (Literals)**:
  - 直接写出的固定值，如 `42` (整型), `3.14` (浮点), `"Hello"` (字符串), `true` (布尔)。
  - Фиксированные значения, записанные напрямую.
- **运算符 / Операторы (Operators)**:
  - 执行操作的符号，如 `+`, `=`, `==`, `<<`, `new`。
  - Символы для выполнения операций.
- **分隔符 / Разделители (Punctuators/Separators)**:
  - 用于界定语法结构，如分号 `;` (语句结束), 大括号 `{}` (代码块), 圆括号 `()` (参数)。
  - Используются для разграничения грамматических структур (например, `;`, `{}`, `()`).

------

### 2. 声明与定义 / Объявления и определения (Declarations & Definitions)

告诉编译器某个实体的名称和类型。

Сообщают компилятору имя и тип сущности.

- **变量声明 / Объявление переменных**: `int count;`
- **函数原型 / Прототипы функций**: `void doWork();`
- **类型定义 / Определение типов**: `struct Point { int x, y; };`

------

### 3. 语句 / Инструкции (Statements)

程序的执行单元，通常以分号 ; 结尾。

Исполняемые единицы программы, обычно заканчиваются точкой с запятой ;.

- **表达式语句 / Выражения**: `x = a + b;`
- **复合语句 (块) / Составные инструкции (Блоки)**: 被 `{ ... }` 包围的一组语句。
- **控制流语句 / Управляющие конструкции**:
  - 选择 (Selection): `if`, `switch`
  - 循环 (Iteration): `for`, `while`, `do-while`
  - 跳转 (Jump): `break`, `return`, `goto`

------

### 4. 预处理指令 / Директивы препроцессора (Preprocessor Directives)

在编译之前处理的指令，以 # 开头。虽然严格来说不是 C++ 编译器语法的一部分，但它是 C++ 程序结构的必要组成。

Инструкции, обрабатываемые перед компиляцией, начинаются с #. Хотя строго говоря это не часть синтаксиса компилятора, это неотъемлемая часть структуры программы C++.

- Examples: `#include <iostream>`, `#define PI 3.14`, `#ifdef`

------

### 5. 注释 / Комментарии (Comments)

被编译器忽略的文本。

Текст, игнорируемый компилятором.

- 单行 / Однострочные: `// ...`
- 多行 / Многострочные: `/* ... */`

------

### 代码解剖示例 / Пример разбора кода

C++

```c
// 5. Comment / Комментарий
#include <iostream> // 4. Preprocessor / Препроцессор

// 2. Declaration / Объявление
int add(int a, int b); 

int main() { // 1. Keyword & Identifier / Ключевое слово и Идентификатор
    // 2. Variable Definition / Определение переменной
    int result = 0; 
    
    // 3. Statement (Control Flow) / Инструкция (Поток управления)
    if (result == 0) {
        // 1. Literal & Operator / Литерал и Оператор
        result = add(10, 20); 
    }
    
    return 0; // 3. Jump Statement / Инструкция перехода
}
```
