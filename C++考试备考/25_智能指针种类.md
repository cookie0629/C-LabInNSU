## 题目 / Вопрос

- **中文**：你知道哪些种类的智能指针？每种智能指针表达的“所有权语义”是什么？分别用于什么场景？  
- **俄文**: Какие виды умных указателей вы знаете? Какие семантики владения выражает каждый вид умных указателей? Для чего применяется каждый вид умных указателей?

在现代 C++（C++11 及以后）中，标准库 `<memory>` 提供了三种核心的智能指针。它们的设计初衷是彻底消除手动调用 `delete` 的需求，并明确资源的所有权生命周期。

以下是中俄互译的详细解析：

------

### 1. `std::unique_ptr` (独占指针 / Уникальный указатель)

这是 C++ 中默认应该使用的智能指针。

(Это умный указатель, который следует использовать по умолчанию.)

- **所有权语义 (Семантика владения)**:

  - 中文: 独占所有权 (Exclusive Ownership)。

    时刻保证只有一个指针指向该对象。它不可复制（Copy），只能移动（Move）。

    语义：“这块内存是我的，谁都别想抢。但我可以把它转让给你。”

  - Русский: Эксклюзивное владение.

    Гарантирует, что на объект указывает только один указатель в любой момент времени. Его нельзя копировать, можно только перемещать.

    Семантика: «Эта память моя. Но я могу передать права на нее тебе».

- **适用场景 (Сценарии использования)**:

  - 绝大多数对象的创建（工厂模式）。
  - 类内部拥有的私有成员（Pimpl 惯用法）。
  - 高性能场景（它的开销和原始指针一样，是零开销抽象）。
  - (*Фабричные функции, члены класса, Pimpl, высокопроизводительный код.*)

------

### 2. `std::shared_ptr` (共享指针 / Разделяемый указатель)

- **所有权语义 (Семантика владения)**:

  - 中文: 共享所有权 (Shared Ownership)。

    多个指针可以同时指向同一个对象。内部维护一个引用计数 (Reference Count)。每多一个指针指向它，计数+1；销毁一个指针，计数-1。当计数归零时，对象被销毁。

    语义：“我们大家都有份，最后一个离开房间的人负责关灯。”

  - Русский: Разделяемое владение.

    Несколько указателей могут ссылаться на один объект. Внутри поддерживается счетчик ссылок. При добавлении указателя счетчик +1, при удалении -1. Объект уничтожается, когда счетчик равен нулю.

    Семантика: «Мы владеем этим сообща, последний уходящий выключает свет».

- **适用场景 (Сценарии использования)**:

  - 对象的所有权不明确，或者确实被多个模块共同使用的场景（如多线程共享资源）。
  - 图结构中的节点（被多条边指向）。
  - (*Неясное владение, общие ресурсы в многопоточности, узлы графов.*)

------

### 3. `std::weak_ptr` (弱指针 / Слабый указатель)

- **所有权语义 (Семантика владения)**:

  - 中文: 非拥有权 / 观察者 (Non-owning / Observer)。

    它指向由 shared_ptr 管理的对象，但不增加引用计数。它像一个旁观者。使用前必须检查对象是否存在（通过 lock() 方法提升为 shared_ptr）。

    语义：“我只看着它，如果它还在，我就用；如果它没了，我就不用。我不决定它的生死。”

  - Русский: Не владеет / Наблюдатель.

    Указывает на объект, управляемый shared_ptr, но не увеличивает счетчик ссылок. Это наблюдатель. Перед использованием нужно проверить, жив ли объект (через метод lock()).

    Семантика: «Я просто смотрю. Если он есть — использую, если нет — нет. Я не решаю, когда ему умереть».

- **适用场景 (Сценарии использования)**:

  - **解决循环引用 (Breaking Reference Cycles)**：这是最重要的用途。如果 A 指向 B，B 指向 A，且都用 `shared_ptr`，内存永远不会释放。必须把其中一端改为 `weak_ptr`。
  - 缓存机制（对象可能被回收）。
  - (*Разрыв циклических ссылок (A->B, B->A), кэширование.*)

------

### 代码对比 (Пример кода)

C++

```c
#include <iostream>
#include <memory>

class Node {
public:
    ~Node() { std::cout << "Node Destroyed\n"; }
};

int main() {
    // 1. unique_ptr: 独占 (Exclusive)
    std::unique_ptr<Node> uPtr = std::make_unique<Node>();
    // std::unique_ptr<Node> uPtr2 = uPtr; // Error! 不可复制 (Compile Error)
    std::unique_ptr<Node> uPtr2 = std::move(uPtr); // OK: 所有权转移 (Ownership Transferred)

    // 2. shared_ptr: 共享 (Shared)
    std::shared_ptr<Node> sPtr1 = std::make_shared<Node>();
    std::shared_ptr<Node> sPtr2 = sPtr1; // OK: 引用计数 = 2 (Ref Count = 2)
    
    // 3. weak_ptr: 观察 (Observer)
    std::weak_ptr<Node> wPtr = sPtr1; // 引用计数仍为 2 (Ref Count still 2)
    
    // 使用 weak_ptr 前必须检查 (Must check before use)
    if (auto tempPtr = wPtr.lock()) { // lock() 返回 shared_ptr
        std::cout << "Object is alive\n";
    }

    return 0;
}
```

### 总结 (Резюме)

| **类型 (Тип)**   | **关键特性 (Ключевая особенность)**        | **核心用途 (Назначение)**                          |
| ---------------- | ------------------------------------------ | -------------------------------------------------- |
| **`unique_ptr`** | 不可复制，零开销 (Non-copyable, Zero-cost) | **默认使用**，独占资源 (Default choice, Exclusive) |
| **`shared_ptr`** | 引用计数 (Reference Counting)              | 共享资源 (Shared resources)                        |
| **`weak_ptr`**   | 不增加计数 (No count increase)             | **打破循环引用** (Break cycles)                    |
