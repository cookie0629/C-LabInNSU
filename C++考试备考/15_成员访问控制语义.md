## 题目 / Вопрос

- **中文**：对于自定义类型的成员访问控制（`public`/`protected`/`private`），分别定义了怎样的语义？  
- **俄文**: Какая семантика определена для видов доступа к членам пользовательского типа данных?

这是 C++ 面向对象编程（OOP）中实现 **封装 (Encapsulation)** 的核心机制。这三种访问修饰符决定了“谁可以访问类中的成员”。

以下是中俄互译的详细解答：

------

### 一、 三种访问级别的语义 (Семантика трех уровней доступа)

#### 1. Public (公有 / Публичный)

- **语义**：**“对所有人开放”**。
  - **中文**：定义了类的**接口 (Interface)**。任何代码（类内部、子类、类外部的函数如 `main`）都可以自由访问 `public` 成员。
  - **Русский**：**«Открыто для всех»**. Определяет **интерфейс (Interface)** класса. Любой код (внутри класса, в подклассах, внешние функции, такие как `main`) может свободно обращаться к членам `public`.

#### 2. Protected (受保护 / Защищенный)

- **语义**：**“仅对家族开放”**。
  - **中文**：这是为**继承 (Inheritance)** 设计的。
    - **类外部**：无法访问（像 private 一样）。
    - **子类**：可以访问（像 public 一样）。
    - 它是父类留给子类的“内部工具”或“扩展点”。
  - **Русский**：**«Только для семьи»**. Предназначено для **наследования (Inheritance)**.
    - **Извне**: Доступ закрыт (как private).
    - **Подклассы**: Доступ открыт (как public).
    - Это «внутренние инструменты» или «точки расширения», оставленные базовым классом для своих наследников.

#### 3. Private (私有 / Приватный)

- **语义**：**“只有自己能看”**。
  - **中文**：这是最严格的封装。
    - 只有**本类**的成员函数（和友元）可以访问。
    - **子类**也**无法**直接访问父类的 `private` 成员。
  - **Русский**：**«Только для себя»**. Это самая строгая инкапсуляция.
    - Только методы **самого класса** (и друзья/friends) имеют доступ.
    - Даже **подклассы не могут** напрямую обращаться к членам `private` базового класса.

------

### 二、 访问权限矩阵 (Матрица доступа)

为了快速记忆，可以参考这张表：

(Для быстрого запоминания обратитесь к этой таблице:)

| **修饰符 (Модификатор)** | **本类内部 (Same Class)** | **子类 (Derived Class)** | **外部代码 (Outside World)** |
| ------------------------ | ------------------------- | ------------------------ | ---------------------------- |
| **public**               | ✅ Yes                     | ✅ Yes                    | ✅ Yes                        |
| **protected**            | ✅ Yes                     | ✅ Yes                    | ❌ No                         |
| **private**              | ✅ Yes                     | ❌ No                     | ❌ No                         |

### 三、 代码示例 (Пример кода)

C++

```
#include <iostream>

class Base {
public:
    int pubVar = 1;    // 所有人可见 (Видно всем)
protected:
    int protVar = 2;   // 子类可见 (Видно подклассам)
private:
    int privVar = 3;   // 只有自己可见 (Видно только себе)
};

class Derived : public Base {
public:
    void testAccess() {
        std::cout << pubVar;   // OK
        std::cout << protVar;  // OK: 子类可以访问 protected (Подкласс видит protected)
        // std::cout << privVar; // Error! 子类不能访问 private (Подкласс не видит private)
    }
};

int main() {
    Base obj;
    std::cout << obj.pubVar;   // OK
    // std::cout << obj.protVar; // Error! 外部不能访问 protected (Извне нельзя к protected)
    // std::cout << obj.privVar; // Error! 外部不能访问 private (Извне нельзя к private)
    return 0;
}
```

### 补充提示 (Дополнительное примечание)

- **默认访问权限 (Доступ по умолчанию)**:
  - `class` 的默认成员是 **private**。
  - `struct` 的默认成员是 **public**。
  - (除了这个默认值区别，C++ 中 class 和 struct 在技术上几乎是一样的。)
  - (*В C++ `class` по умолчанию **private**, а `struct` — **public**. В остальном они технически почти идентичны.*)
- **友元 (Friend / Друзья)**:
  - `friend` 关键字可以打破上述所有规则，允许外部函数或类访问 `private` 和 `protected` 成员。
  - (*Ключевое слово `friend` нарушает все вышеуказанные правила, позволяя внешним функциям или классам получать доступ к `private` и `protected`.*)
