## 题目 / Вопрос

- **中文**：什么是 C++ 的流式输入/输出库？你知道它设计中的哪些主要元素？  
- **俄文**: Что такое библиотека потоков ввода/вывода? Какие основные элементы дизайна данной библиотеки вы знаете?

C++ 的流式输入/输出库（IOStream Library）是一个**面向对象的、类型安全的、可扩展的** I/O 抽象层。它将输入和输出设备抽象为“字节流”。

Библиотека потоков ввода/вывода C++ (IOStream Library) — это **объектно-ориентированный, типобезопасный и расширяемый** слой абстракции. Она представляет устройства ввода и вывода как «потоки байтов».

Ее дизайн включает следующие ключевые элементы:

### 1. 职责分离：格式化与缓冲 / Разделение: Форматирование и Буферизация

这是该库最精彩的设计模式（Strategy Pattern 的一种变体）。

Это самый блестящий паттерн в дизайне библиотеки (вариация паттерна Стратегия).

- **`std::streambuf` (底层传输 / Транспорт)**:
  - **中文**: 负责**实际的字节传输**和缓冲管理。它不知道什么是 `int` 或 `float`，只知道字符和内存/文件/硬件之间的搬运。
  - **Русский**: Отвечает за **фактическую передачу байтов** и управление буфером. Он не знает, что такое `int` или `float`, он просто перемещает символы между памятью/файлом/железом.
- **`std::istream` / `std::ostream` (高层格式化 / Форматирование)**:
  - **中文**: 负责**数据的解析和格式化**。它将 `int` 转换为字符序列，然后交给 `streambuf` 处理。
  - **Русский**: Отвечает за **парсинг и форматирование данных**. Преобразует `int` в последовательность символов, а затем передает их в `streambuf`.

### 2. 类继承体系 / Иерархия классов

- **`std::ios_base`**: 祖先类，管理格式标志（如 hex, dec）、错误状态和精度。不依赖模板参数。
- **`std::ios`**: 继承自 `ios_base`，持有指向 `streambuf` 的指针。
- **`std::istream` / `std::ostream`**: 定义了 `>>` and `<<` 接口。
- **`std::ifstream` / `std::ofstream`**: 针对文件的具体实现。
- **`std::ios_base`**: Предок, управляет флагами формата (hex, dec), состоянием ошибок и точностью. Не зависит от параметров шаблона.
- **`std::ios`**: Наследуется от `ios_base`, хранит указатель на `streambuf`.
- **`std::istream` / `std::ostream`**: Определяют интерфейсы `>>` и `<<`.
- **`std::ifstream` / `std::ofstream`**: Конкретные реализации для файлов.

### 3. 本地化策略 / Локализация (Locales & Facets)

- **中文**: 这是一个可插拔的策略。`std::locale` 包含多个 `facet`（刻面），用于处理不同文化的数字格式（逗号还是点）、货币符号和时间格式。
- **Русский**: Это подключаемая стратегия. `std::locale` содержит несколько `facet` (фасетов), которые обрабатывают культурные различия в форматах чисел (запятая или точка), валют и времени.

### 4. 操纵符 / Манипуляторы (Manipulators)

- **中文**: 特殊的函数对象（如 `std::endl`, `std::hex`），可以作为流操作符 `<<` 的右操作数，用于修改流的内部状态。
- **Русский**: Специальные объекты-функции (например, `std::endl`, `std::hex`), которые могут выступать правым операндом оператора `<<` для изменения внутреннего состояния потока.

### 代码示例：重定向输出 (利用 streambuf) / Пример: Перенаправление вывода

这个例子展示了设计元素 #1 的威力：我们可以偷换底层 buffer，而不改变上层代码。

Этот пример демонстрирует мощь элемента №1: мы подменяем нижний буфер, не меняя верхний код.

C++

```C++
#include <iostream>
#include <fstream>

int main() {
    // 打开一个文件
    // Открываем файл
    std::ofstream file("log.txt");

    // 1. 保存原始的 cout buffer
    // 1. Сохраняем оригинальный буфер cout
    std::streambuf* originalBuffer = std::cout.rdbuf();

    // 2. 将 cout 的 buffer 替换为文件的 buffer
    // 2. Подменяем буфер cout на буфер файла
    std::cout.rdbuf(file.rdbuf());

    // 3. 所有写入 cout 的内容现在都会写入文件
    // 3. Всё, что пишется в cout, теперь попадает в файл
    std::cout << "This goes to the file, not the screen!" << std::endl;

    // 4. 恢复原始 buffer
    // 4. Восстанавливаем оригинальный буфер
    std::cout.rdbuf(originalBuffer);

    std::cout << "This goes back to the screen." << std::endl;

    return 0;
}
```
