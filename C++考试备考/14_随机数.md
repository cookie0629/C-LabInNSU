## 题目 / Вопрос

- **中文**：在 C++ 中怎样使用随机数（随机数库）？  
- **俄文**: Как работать со случайными числами в C++?

在 C++11 及其之后的现代 C++ 中，**绝对不建议**继续使用 C 语言风格的 `rand()` 和 `srand()`。

现代 C++ 引入了 `<random>` 库，它采用了 **“引擎 (Engine) + 分布 (Distribution)”** 的分离设计模式。

以下是中俄互译的详细解答：

------

### 一、 核心概念 (Основные концепции)

现代随机数生成器由三个部分组成：

(Генератор случайных чисел состоит из трех частей:)

1. **种子源 (Seed Source / Источник зерна)**:
   - **中文**：用于初始化引擎。通常使用 `std::random_device`，它请求操作系统提供非确定性的熵（真随机数）。
   - **Русский**：Используется для инициализации движка. Обычно используется `std::random_device`, который запрашивает у ОС недетерминированную энтропию (истинно случайные числа).
2. **引擎 (Engine / Движок)**:
   - **中文**：负责生成原始的随机比特流。最常用且推荐的是 **Mersenne Twister (`std::mt19937`)**。它速度快，周期极长，质量远超 `rand()`。
   - **Русский**：Отвечает за генерацию потока случайных битов. Самый популярный и рекомендуемый — **Вихрь Мерсенна (`std::mt19937`)**. Он быстрый, имеет огромный период и качество, значительно превосходящее `rand()`.
3. **分布 (Distribution / Распределение)**:
   - **中文**：将引擎生成的原始随机数映射到你想要的范围和数学分布（如 1-100 的整数，0.0-1.0 的浮点数，或者正态分布）。
   - **Русский**：Преобразует сырые случайные числа от движка в нужный диапазон и математическое распределение (например, целые числа 1-100, float 0.0-1.0 или нормальное распределение).

------

### 二、 标准写法示例 (Пример стандартного кода)

这是一个生成 [1, 100] 之间随机整数的标准模板。

(Это стандартный шаблон для генерации случайного целого числа в диапазоне [1, 100].)

C++

```c
#include <iostream>
#include <random> // 必须包含 (Обязательно подключить)

int main() {
    // 1. 获取物理种子 (Получение физического зерна)
    // 这里的 random_device 向操作系统请求真随机数
    std::random_device rd;

    // 2. 初始化引擎 (Инициализация движка)
    // 使用梅森旋转算法 (Mersenne Twister)
    std::mt19937 gen(rd());

    // 3. 定义分布 (Определение распределения)
    // 闭区间 [min, max] (Закрытый диапазон)
    std::uniform_int_distribution<> dis(1, 100);

    // 4. 生成随机数 (Генерация числа)
    // 将引擎传递给分布对象
    int random_number = dis(gen);

    std::cout << "Random Number: " << random_number << std::endl;

    return 0;
}
```

------

### 三、 常用分布类型 (Типы популярных распределений)

| **需求 (Задача)**              | **分布类 (Класс распределения)** | **示例 (Пример)**            |
| ------------------------------ | -------------------------------- | ---------------------------- |
| **整数范围** (Integer Range)   | `std::uniform_int_distribution`  | `dis(1, 6)` // 骰子 (Dice)   |
| **浮点数范围** (Real Range)    | `std::uniform_real_distribution` | `dis(0.0, 1.0)`              |
| **布尔值** (Boolean)           | `std::bernoulli_distribution`    | `dis(0.5)` // 50% true/false |
| **正态分布** (Normal/Gaussian) | `std::normal_distribution`       | `dis(mean, std_dev)`         |

------

### 四、 为什么要抛弃 `rand()`? (Почему стоит отказаться от `rand()`?)

1. **取模偏差 (Modulo Bias / Смещение по модулю)**:
   - **中文**：写法 `rand() % N` 会导致较小的数字出现概率略高，破坏均匀性。`std::uniform_int_distribution` 完美解决了这个问题。
   - **Русский**：Запись `rand() % N` приводит к тому, что меньшие числа выпадают чуть чаще, нарушая равномерность. `std::uniform_int_distribution` идеально решает эту проблему.
2. **质量低 (Low Quality / Низкое качество)**:
   - **中文**：`rand()` 通常基于简单的线性同余生成器 (LCG)，周期短，容易预测。
   - **Русский**：`rand()` обычно основан на простом линейном конгруэнтном методе (LCG), имеет короткий период и легко предсказуем.

### 性能提示 (Совет по производительности)

- **中文**：`std::mt19937` 的状态比较大（超过 2KB）。如果在循环中频繁创建和销毁引擎，效率会很低。**建议将引擎设为 `static` 或者放在类成员中复用。**
- **Русский**：Состояние `std::mt19937` довольно велико (более 2 КБ). Если часто создавать и уничтожать движок в цикле, эффективность будет низкой. **Рекомендуется сделать движок `static` или использовать его как член класса для повторного использования.**
