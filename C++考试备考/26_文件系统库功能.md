## 题目 / Вопрос

- **中文**：标准库的文件系统库（`<filesystem>`）提供了哪些功能？  
- **俄文**: Какие возможности предоставляет стандартная библиотека файловой системы?

C++17 引入的 `<filesystem>` 库（通常简写为 `fs`）是一个现代化的、跨平台的库，专门用于处理文件路径、目录遍历和文件操作。它极大地简化了以前需要调用操作系统原生 API（如 Windows API 或 POSIX）才能完成的任务。

以下是中俄互译的功能详解：

------

### 1. 路径处理 (Path Manipulation / Работа с путями)

核心类是 std::filesystem::path。

(Основным классом является std::filesystem::path.)

- **功能**:
  - **跨平台兼容**: 自动处理不同系统的路径分隔符（Windows 的 `\` 和 Linux 的 `/`）。
  - **解析与组合**: 可以轻松提取文件名、扩展名、父目录，或使用 `/` 运算符连接路径。
- **Функции**:
  - **Кроссплатформенность**: Автоматически обрабатывает разделители путей для разных ОС (`\` в Windows и `/` в Linux).
  - **Парсинг и композиция**: Легкое извлечение имени файла, расширения, родительского каталога или объединение путей с помощью оператора `/`.

### 2. 目录遍历 (Directory Iteration / Обход каталогов)

不再需要写复杂的递归函数。

(Больше не нужно писать сложные рекурсивные функции.)

- **`directory_iterator`**: 迭代当前目录下的文件（非递归）。
  - *(Итерация по файлам в текущем каталоге (без рекурсии).)*
- **`recursive_directory_iterator`**: 自动递归遍历子目录。
  - *(Автоматический рекурсивный обход подкаталогов.)*

### 3. 文件状态查询 (Querying File Status / Запрос статуса файла)

在不打开文件的情况下获取元数据。

(Получение метаданных без открытия файла.)

- **检查**: `exists()` (是否存在), `is_directory()` (是目录吗), `is_regular_file()` (是普通文件吗).
- **属性**: `file_size()` (文件大小), `last_write_time()` (最后修改时间), `space_info()` (磁盘剩余空间).
- **Проверка**: `exists()`, `is_directory()`, `is_regular_file()`.
- **Атрибуты**: `file_size()`, `last_write_time()`, `space_info()` (свободное место на диске).

### 4. 文件系统操作 (Filesystem Operations / Операции с файловой системой)

执行实际的增删改操作。

(Выполнение операций создания, удаления и изменения.)

- **创建**: `create_directory()`, `create_directories()` (创建多级目录 `mkdir -p`).
- **修改**: `copy()`, `rename()` (重命名或移动), `resize_file()`.
- **删除**: `remove()` (删除单个文件), `remove_all()` (递归删除文件夹 `rm -rf`).
- **Создание**: `create_directory()`, `create_directories()` (создание вложенных папок).
- **Изменение**: `copy()`, `rename()`, `resize_file()`.
- **Удаление**: `remove()`, `remove_all()` (рекурсивное удаление).

------

### 代码示例 (Пример кода)

C++

```c
#include <iostream>
#include <filesystem>
#include <fstream>

// 通常我们会创建一个别名 (Обычно мы создаем псевдоним)
namespace fs = std::filesystem;

int main() {
    fs::path dir = "sandbox";
    fs::path file = dir / "test.txt"; // 自动处理分隔符 (Auto separator)

    // 1. 创建目录 (Создание каталога)
    if (!fs::exists(dir)) {
        fs::create_directory(dir);
        std::cout << "Directory created.\n";
    }

    // 2. 创建文件 (Создание файла)
    std::ofstream(file) << "Hello Filesystem!";

    // 3. 遍历并打印信息 (Обход и вывод информации)
    for (const auto& entry : fs::directory_iterator(dir)) {
        std::cout << "File: " << entry.path().filename() << "\n";
        std::cout << "Size: " << fs::file_size(entry) << " bytes\n";
    }

    // 4. 获取绝对路径 (Получение абсолютного пути)
    std::cout << "Absolute: " << fs::absolute(file) << "\n";

    // 5. 清理 (Очистка)
    // fs::remove_all(dir); 

    return 0;
}
```

### 总结 (Резюме)

| **功能 (Функция)** | **关键函数/类 (Ключевые сущности)** | **作用 (Роль)**                                 |
| ------------------ | ----------------------------------- | ----------------------------------------------- |
| **Path**           | `fs::path`                          | 路径字符串处理 (String path manipulation)       |
| **Traversal**      | `directory_iterator`                | 像遍历容器一样遍历文件夹 (Loop through folders) |
| **Query**          | `exists`, `file_size`               | 获取属性 (Get attributes)                       |
| **Modify**         | `copy`, `rename`, `remove`          | 管理文件 (Manage files)                         |
