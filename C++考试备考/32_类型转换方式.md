## 题目 / Вопрос

- **中文**：在 C 和 C++ 中，你知道哪些类型转换方式？每种转换方式用于什么场景？  
- **俄文**: Какие способы приведения типа в C и C++ вы знаете? Для чего используется каждый из способов?

在 C 和 C++ 中，类型转换（Type Casting）是将一种数据类型转换为另一种数据类型的过程。C++ 引入了 4 种特定的转换操作符来替代 C 风格的“暴力”转换，以提高代码的安全性和可读性。

В C и C++ приведение типов (Type Casting) — это процесс преобразования одного типа данных в другой. C++ ввел 4 специфических оператора приведения, чтобы заменить «грубое» приведение в стиле C, повышая безопасность и читаемость кода.

------

### 1. C 语言风格 / Стиль C (C-Style Cast)

- **语法 / Синтаксис**: `(type)expression` 或 `type(expression)`
- **中文**: 这是最古老且最“万能”的转换方式。它尝试按照 `static_cast`、`const_cast` 或 `reinterpret_cast` 的顺序进行转换。
  - *缺点*: 难以在代码中搜索，且过于强大，容易掩盖逻辑错误（例如将整数强转为指针）。
- **Русский**: Самый старый и «универсальный» способ. Он пытается выполнить преобразование в порядке `static_cast`, `const_cast` или `reinterpret_cast`.
  - *Минус*: Трудно найти в коде, и он слишком мощный, что может скрыть логические ошибки (например, приведение int к указателю).

------

### 2. C++ 四种标准转换 / 4 оператора приведения C++

为了更安全，C++ 推荐使用以下四种专用操作符：

Для безопасности C++ рекомендует использовать следующие четыре оператора:

#### **A. `static_cast`**

- **中文**: **最常用的转换**。用于良性转换和编译器隐式转换。
  - **场景**: 基本类型互转（如 `int` 转 `float`）、父子类指针的**上行转换**（派生类 -> 基类）、调用显式构造函数。它在**编译时**进行检查。
- **Русский**: **Самое частое приведение**. Используется для «разумных» и неявных преобразований.
  - **Сценарий**: Преобразование базовых типов (`int` в `float`), **восходящее приведение** указателей (Derived -> Base), вызов явных конструкторов. Проверка выполняется **во время компиляции**.

#### **B. `dynamic_cast`**

- **中文**: 专门用于处理**多态**。
  - **场景**: 安全的**下行转换**（基类指针 -> 派生类指针）。它在**运行时**检查类型信息（RTTI）。如果转换失败，指针返回 `nullptr`，引用抛出 `std::bad_cast` 异常。**前提：基类必须有虚函数**。
- **Русский**: Специально для **полиморфизма**.
  - **Сценарий**: Безопасное **нисходящее приведение** (Base* -> Derived*). Проверяет информацию о типах (RTTI) **во время выполнения**. Если не удается, указатель возвращает `nullptr`, ссылка выбрасывает исключение. **Условие: в базовом классе должны быть виртуальные функции**.

#### **C. `const_cast`**

- **中文**: 唯一能**去除或增加 `const` / `volatile` 属性**的转换。
  - **场景**: 当你需要调用一个未声明为 `const` 的旧 API，但你手里只有一个 `const` 指针时。**注意**：修改原本就是 `const` 的对象会导致未定义行为。
- **Русский**: Единственное приведение, способное **снять или добавить `const` / `volatile`**.
  - **Сценарий**: Когда нужно вызвать старый API, не принимающий `const`, а у вас есть только `const` указатель. **Важно**: Изменение объекта, который изначально был константой, ведет к неопределенному поведению (UB).

#### **D. `reinterpret_cast`**

- **中文**: **最危险的转换**。它仅对二进制位进行重新解释，不改变实际的位模式。
  - **场景**: 指针转整数、整数转指针、完全不相关的指针类型互转。通常用于底层系统编程或硬件驱动开发。
- **Русский**: **Самое опасное приведение**. Просто переинтерпретирует биты, не меняя их шаблон.
  - **Сценарий**: Указатель в int, int в указатель, приведение между несвязанными типами указателей. Обычно используется в системном программировании или драйверах.

### 代码示例 / Пример кода

C++

```c
#include <iostream>

class Base { public: virtual ~Base() {} }; // 需要虚函数以支持 dynamic_cast
class Derived : public Base { public: void specific() {} };

int main() {
    // 1. static_cast
    double pi = 3.14159;
    int num = static_cast<int>(pi); // OK: 3

    // 2. const_cast
    const char* message = "Hello";
    // char* modifiable = static_cast<char*>(message); // Error!
    char* modifiable = const_cast<char*>(message); // OK, but don't modify *modifiable!

    // 3. dynamic_cast
    Base* b = new Derived();
    Derived* d = dynamic_cast<Derived*>(b); // OK: Runtime check passes
    if (d) {
        d->specific();
    }
    
    Base* b2 = new Base();
    Derived* d2 = dynamic_cast<Derived*>(b2); // OK: Returns nullptr (safe failure)

    // 4. reinterpret_cast
    long address = reinterpret_cast<long>(b); // Pointer to Integer
    
    delete b;
    delete b2;
    return 0;
}
```

### 总结表格 / Сводная таблица

| **转换方式 / Тип** | **检查时间 / Проверка** | **典型用途 / Типичное использование**              | **安全性 / Безопасность**        |
| ------------------ | ----------------------- | -------------------------------------------------- | -------------------------------- |
| `static_cast`      | 编译时 / Compile-time   | 值转换, 上行转换 / Преобразование значений, Upcast | 高 / Высокая                     |
| `dynamic_cast`     | 运行时 / Runtime        | 多态下行转换 / Downcast в полиморфизме             | 高 (带开销) / Высокая (медленно) |
| `const_cast`       | 编译时 / Compile-time   | 去除 const / Снятие const                          | 低 / Низкая                      |
| `reinterpret_cast` | 无 / None               | 位重解释, 硬件操作 / Битовая магия, железо         | 极低 / Очень низкая              |
