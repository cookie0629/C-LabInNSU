## 题目 / Вопрос

- **中文**：什么是“模板特化”？你知道哪些类型的模板特化？函数模板和类模板的特化有何不同？  
- **俄文**: Что такое специализация шаблона? Какие виды специализации шаблона вы знаете? В чем отличие специализаций шаблонов функций и пользовательских типов данных?

**模板特化 (Template Specialization)** 是 C++ 泛型编程中处理“特殊情况”的机制。它允许你为特定的数据类型提供一个定制的实现版本，而不是使用通用的模板。

**Специализация шаблона (Template Specialization)** — это механизм обработки «особых случаев» в обобщенном программировании на C++. Она позволяет предоставить кастомизированную реализацию для конкретного типа данных вместо использования общего шаблона.

------

### 1. 两种特化类型 / Два вида специализации

#### **A. 全特化 / Полная специализация (Full/Explicit Specialization)**

- **中文**: 将模板中的**所有**参数都指定为具体的类型。
  - 语法: `template<> class MyClass<int> { ... };`
- **Русский**: Все параметры шаблона заменяются на **конкретные** типы.
  - Синтаксис: `template<> class MyClass<int> { ... };`

#### **B. 偏特化 / Частичная специализация (Partial Specialization)**

- **中文**: 只指定**部分**模板参数，或者对参数进行**限制**（如指针 `T*` 或引用 `T&`）。
  - 语法: `template<typename T> class MyClass<T*> { ... };`
- **Русский**: Задаются только **некоторые** параметры, или накладываются **ограничения** (например, указатели `T*` или ссылки `T&`).
  - Синтаксис: `template<typename T> class MyClass<T*> { ... };`

------

### 2. 类模板 vs 函数模板 / Шаблоны классов vs Функций

这是面试中的核心考点，区别非常关键：

Это ключевой вопрос на собеседованиях, различие критично:

| **特性 / Характеристика**   | **类模板 / Классы**         | **函数模板 / Функции**                                       |
| --------------------------- | --------------------------- | ------------------------------------------------------------ |
| **全特化 / Полная**         | ✅ 支持 / Поддерживается     | ✅ 支持 / Поддерживается                                      |
| **偏特化 / Частичная**      | ✅ **支持 / Поддерживается** | ❌ **不支持 / Не поддерживается**                             |
| **替代方案 / Альтернатива** | N/A                         | 使用**函数重载** (Function Overloading)   Использовать **перегрузку функций** |

> **关键规则**: C++ 标准禁止对函数模板进行偏特化。如果你需要针对特定条件的函数逻辑（例如“针对所有指针类型”），你应该使用**重载**。
>
> **Важное правило**: Стандарт C++ запрещает частичную специализацию шаблонов функций. Если вам нужна особая логика функции для группы типов (например, "для всех указателей"), следует использовать **перегрузку**.

------

### 代码示例 / Пример кода

C++

```c
#include <iostream>

// ==========================================
// 1. 类模板 (支持全特化和偏特化)
// 1. Шаблон класса (Поддерживает полную и частичную)
// ==========================================

// 通用版本 / Общая версия
template <typename T, typename U>
struct DataPair {
    void print() { std::cout << "General Template" << std::endl; }
};

// 全特化 / Полная специализация (int, int)
template <>
struct DataPair<int, int> {
    void print() { std::cout << "Full Specialization <int, int>" << std::endl; }
};

// 偏特化 / Частичная специализация (T, T) - 两个类型相同
template <typename T>
struct DataPair<T, T> {
    void print() { std::cout << "Partial Specialization <T, T>" << std::endl; }
};

// 偏特化 / Частичная специализация (T*, U*) - 指针类型
template <typename T, typename U>
struct DataPair<T*, U*> {
    void print() { std::cout << "Partial Specialization <Pointer, Pointer>" << std::endl; }
};

// ==========================================
// 2. 函数模板 (仅支持全特化)
// 2. Шаблон функции (Только полная)
// ==========================================

// 通用版本 / Общая версия
template <typename T>
void func(T x) {
    std::cout << "General Function Template" << std::endl;
}

// 全特化 / Полная специализация
template <>
void func<int>(int x) {
    std::cout << "Full Specialization for int" << std::endl;
}

// ❌ 错误：函数不支持偏特化
// ❌ Ошибка: Функции не поддерживают частичную специализацию
// template <typename T>
// void func<T*>(T* x) { ... } 

// ✅ 正确做法：使用重载代替偏特化
// ✅ Правильно: Использовать перегрузку
template <typename T>
void func(T* x) {
    std::cout << "Overloaded Function for Pointers" << std::endl;
}

int main() {
    // Class tests
    DataPair<char, float> d1; d1.print(); // General
    DataPair<int, int> d2;    d2.print(); // Full <int, int>
    DataPair<float, float> d3; d3.print(); // Partial <T, T>
    DataPair<int*, double*> d4; d4.print(); // Partial <Ptr, Ptr>

    // Function tests
    func(10.5); // General
    func(10);   // Full Specialization
    int a = 10;
    func(&a);   // Overload (mimics partial specialization)

    return 0;
}
```
