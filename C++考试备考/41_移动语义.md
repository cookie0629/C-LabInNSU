## 题目 / Вопрос

- **中文**：请解释 C++ 中的“移动语义”。语言中哪两种构造（机制）支持这种语义？  
- **俄文**: Объясните семантику перемещения в C++? Какие две конструкции языка позволяют осуществлять данную семантику?

**移动语义 (Move Semantics)** 是 C++11 引入的一项核心特性，旨在大幅提高性能。

**Семантика перемещения (Move Semantics)** — это ключевая возможность, введенная в C++11, направленная на значительное повышение производительности.

------

### 1. 什么是移动语义？ / Что такое семантика перемещения?

- **中文**:
  - **核心概念**: 它允许我们将资源（如堆内存、文件句柄）的所有权从一个对象**转移**到另一个对象，而不是进行昂贵的**复制**（Deep Copy）。
  - **比喻**: 就像你是要把房子里的家具给别人。
    - **复制语义**: 你买了一套完全一样的新家具送给他（既慢又贵）。
    - **移动语义**: 你直接把房子的钥匙交给他（极快，零成本）。
  - **结果**: 源对象（被移动的对象）会被置于一个“有效但未指定”的状态（通常是空的），以便安全析构。
- **Русский**:
  - **Основная концепция**: Она позволяет **передавать** владение ресурсами (такими как память в куче, файловые дескрипторы) от одного объекта к другому, вместо выполнения дорогостоящего **копирования** (Deep Copy).
  - **Аналогия**: Вы хотите передать мебель из дома кому-то другому.
    - **Семантика копирования**: Вы покупаете точно такую же новую мебель и отдаете её (медленно и дорого).
    - **Семантика перемещения**: Вы просто отдаете ключи от дома (мгновенно и бесплатно).
  - **Результат**: Исходный объект (из которого переместили) остается в «валидном, но неопределенном» состоянии (обычно пустом), чтобы его можно было безопасно уничтожить.

------

### 2. 支持它的两种机制 / Две конструкции, поддерживающие это

为了实现移动语义，C++ 引入了两个特定的语言构造：

Для реализации семантики перемещения C++ ввел две специфические языковые конструкции:

#### **A. 右值引用 / Rvalue-ссылки (`&&`)**

- **中文**:
  - 这是语法基础。通过使用双 `&` 符号（如 `int&&` 或 `String&&`），我们可以区分**临时对象**（即将被销毁的对象，即右值）和持久对象（左值）。
  - 编译器如果看到参数是 `&&`，它就知道：“这个对象快要死了，你可以安全地偷走它的资源。”
- **Русский**:
  - Это синтаксическая основа. Используя двойной амперсанд (`int&&` или `String&&`), мы можем отличить **временные объекты** (которые скоро будут уничтожены, т.е. rvalue) от постоянных объектов (lvalue).
  - Если компилятор видит аргумент с `&&`, он понимает: «Этот объект скоро умрет, можно безопасно украсть его ресурсы».

#### **B. 移动构造函数与移动赋值运算符 / Конструктор перемещения и Оператор присваивания перемещением**

- **中文**:
  - 这是实现逻辑的地方。类需要定义特殊的成员函数来处理资源的转移。
  - **移动构造函数**: `ClassName(ClassName&& other)`
  - **移动赋值**: `ClassName& operator=(ClassName&& other)`
  - 在这些函数内部，你会做“浅拷贝”并将原指针置空 (`nullptr`)。
- **Русский**:
  - Это место реализации логики. Класс должен определить специальные функции-члены для обработки передачи ресурсов.
  - **Конструктор перемещения**: `ClassName(ClassName&& other)`
  - **Перемещение при присваивании**: `ClassName& operator=(ClassName&& other)`
  - Внутри этих функций выполняется «поверхностное копирование», а исходный указатель обнуляется (`nullptr`).

### 代码示例 / Пример кода

C++

```c
#include <iostream>
#include <cstring>
#include <utility> // for std::move

class StringData {
private:
    char* data;
    int size;

public:
    // 1. 普通构造函数 / Обычный конструктор
    StringData(const char* str) {
        size = strlen(str);
        data = new char[size + 1];
        strcpy(data, str);
        std::cout << "Allocated (Created)\n";
    }

    // 2. 拷贝构造函数 (Deep Copy) / Конструктор копирования
    // 这种方式很慢 / Это медленно
    StringData(const StringData& other) {
        size = other.size;
        data = new char[size + 1];
        strcpy(data, other.data);
        std::cout << "Copied (Deep Copy)\n";
    }

    // 3. 移动构造函数 (Move Semantics) / Конструктор перемещения
    // 关键点：参数是 && / Ключевой момент: аргумент &&
    StringData(StringData&& other) noexcept {
        // "Steal" the resources / "Крадем" ресурсы
        data = other.data;
        size = other.size;

        // Nullify the source / Обнуляем источник
        other.data = nullptr;
        other.size = 0;
        
        std::cout << "Moved (Resource Stolen)\n";
    }

    ~StringData() {
        delete[] data; // nullptr deletion is safe
    }
};

int main() {
    StringData a("Hello");
    
    // Calls Copy Constructor / Вызывает конструктор копирования
    StringData b = a; 
    
    // Calls Move Constructor / Вызывает конструктор перемещения
    // std::move 强制将 a 转换为右值引用
    // std::move принудительно преобразует a в rvalue-ссылку
    StringData c = std::move(a); 
    
    return 0;
}
```

### 总结 / Резюме

| **机制 / Механизм**     | **作用 / Роль**                                              |
| ----------------------- | ------------------------------------------------------------ |
| **Type&& (Rvalue Ref)** | **识别**: 告诉编译器这是一个可以被“打劫”的临时对象。   **Идентификация**: Говорит компилятору, что это временный объект, который можно «ограбить». |
| **Move Constructor**    | **执行**: 实际执行指针交换和置空操作的代码。   **Исполнение**: Код, который фактически меняет указатели и обнуляет источник. |
