## 题目 / Вопрос

- **中文**：什么是“格式化”和“非格式化”输入/输出？在标准库中分别通过哪些设施来实现？  
- **俄文**: Что такое форматированный и неформатированный ввод/вывод? Какими средствами он представлен в стандартной библиотеке?

在 C++ I/O 流库中，这是两种截然不同的数据处理范式。核心区别在于：**数据在传输过程中是否发生了“文本表示”与“二进制内部表示”之间的转换。**

以下是中俄互译的详细解答：

------

### 1. 格式化 I/O (Formatted I/O / Форматированный ввод/вывод)

这是我们最常使用的模式，主要用于处理人类可读的文本。

(Это наиболее часто используемый режим, в основном для обработки человекочитаемого текста.)

- **定义 (Определение)**:
  - **中文**: 数据在传输前会经过解释和转换。
    - **输入**: 字符序列 -> 解析 -> 内部数据类型（如 "123" -> `int` 123）。默认会**跳过空白字符**（空格、换行）。
    - **输出**: 内部数据类型 -> 格式化 -> 字符序列（如 `int` 123 -> "123"）。
  - **Русский**: Данные интерпретируются и преобразуются перед передачей.
    - **Ввод**: Последовательность символов -> Парсинг -> Внутренний тип (напр., "123" -> `int` 123). По умолчанию **пропускает пробельные символы**.
    - **Вывод**: Внутренний тип -> Форматирование -> Последовательность символов (напр., `int` 123 -> "123").
- **实现设施 (Средства реализации)**:
  - **流运算符重载 (Overloaded Stream Operators)**:
    - `operator<<` (插入 / Insertion)
    - `operator>>` (提取 / Extraction)
  - **流操纵符 (Stream Manipulators)**:
    - `std::setw`, `std::setprecision`, `std::hex`, `std::boolalpha`.

------

### 2. 非格式化 I/O (Unformatted I/O / Неформатированный ввод/вывод)

这种模式主要用于二进制文件处理或底层字符操作。

(Этот режим используется в основном для обработки бинарных файлов или низкоуровневых операций с символами.)

- **定义 (Определение)**:
  - **中文**: 数据作为**原始字节块 (Raw Bytes)** 直接传输，不进行任何类型转换，也不进行格式解析。
    - **输入**: 读取指定数量的字节，不跳过空格。
    - **输出**: 将内存中的字节原样写入流。
  - **Русский**: Данные передаются напрямую как **блоки сырых байтов**, без какого-либо преобразования типов или парсинга формата.
    - **Ввод**: Читает указанное количество байтов, не пропуская пробелы.
    - **Вывод**: Записывает байты из памяти в поток "как есть".
- **实现设施 (Средства реализации)**:
  - **成员函数 (Member Functions)**:
    - **Input**: `get()`, `getline()`, `read()`, `ignore()`, `gcount()`.
    - **Output**: `put()`, `write()`.

------

### 3. 代码对比 (Сравнение кода)

假设我们有一个整数 `int num = 123456;` (假设 int 占 4 字节)。

#### 格式化 (Formatted)

C++

```c
#include <iostream>
#include <fstream>

int main() {
    int num = 123456;
    
    // 写入的是文本 "123456" (6 个字节)
    // Записывается текст "123456" (6 байтов)
    std::cout << num << std::endl; 
    
    // 输入时会自动解析文本
    // При вводе текст автоматически парсится
    std::cin >> num; 
}
```

#### 非格式化 (Unformatted)

C++

```c
#include <iostream>
#include <fstream>

int main() {
    int num = 123456;
    
    // 写入的是内存中的 4 个原始字节 (例如二进制补码)
    // Записываются 4 сырых байта из памяти (например, дополнение до двух)
    std::cout.write(reinterpret_cast<const char*>(&num), sizeof(num));
    
    // 读取原始字节回填到变量内存中
    // Читает сырые байты обратно в память переменной
    std::cin.read(reinterpret_cast<char*>(&num), sizeof(num));
}
```

### 总结 (Резюме)

| **特性 (Характеристика)**  | **格式化 (Formatted)**                         | **非格式化 (Unformatted)**                           |
| -------------------------- | ---------------------------------------------- | ---------------------------------------------------- |
| **主要工具 (Инструменты)** | `<<`, `>>`                                     | `read()`, `write()`, `get()`                         |
| **效率 (Эффективность)**   | 较低 (需解析转换)   Низкая (требуется парсинг) | **高 (内存拷贝)**   **Высокая (копирование памяти)** |
| **空白字符 (Пробелы)**     | 默认跳过 (Skip)                                | **不跳过 (No skip)**                                 |
| **用途 (Назначение)**      | 文本文件, UI 交互                              | 二进制文件, 加密, 序列化                             |
