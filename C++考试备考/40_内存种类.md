## 题目 / Вопрос

- **中文**：在 C++ 程序中，我们可以将内存分为哪几类？每一类内存有什么特点？  
- **俄文**: На какие типы мы можем разделить память программы на C++? В чем особенности каждого типа памяти?

在 C++ 程序中，内存通常被划分为 5 个主要区域。这种划分有助于管理变量的生命周期、作用域和访问速度。

В программе на C++ память обычно разделяется на 5 основных областей. Это разделение помогает управлять временем жизни переменных, областью видимости и скоростью доступа.

------

### 1. 栈区 / Стек (Stack)

- **中文**:
  - **用途**: 存储函数的参数值、局部变量、返回地址。
  - **特点**: 由编译器**自动分配和释放**。遵循 **LIFO** (后进先出) 原则。
  - **性能**: 访问速度最快，但空间有限（通常只有几 MB）。如果递归过深或分配过大数组，会导致“栈溢出” (Stack Overflow)。
- **Русский**:
  - **Назначение**: Хранит аргументы функций, локальные переменные, адреса возврата.
  - **Особенности**: **Автоматически** выделяется и освобождается компилятором. Работает по принципу **LIFO** (последним пришел — первым ушел).
  - **Производительность**: Самый быстрый доступ, но ограниченный размер (обычно несколько МБ). Глубокая рекурсия или огромные массивы ведут к «переполнению стека» (Stack Overflow).

### 2. 堆区 / Куча (Heap)

- **中文**:
  - **用途**: 用于动态内存分配（如 `new`, `malloc`）。
  - **特点**: 由程序员**手动控制**（分配和释放）。如果不释放，会导致**内存泄漏** (Memory Leak)。
  - **性能**: 空间非常大（受限于物理内存和虚拟内存），但访问速度比栈慢，且频繁分配容易产生**内存碎片**。
- **Русский**:
  - **Назначение**: Используется для динамического выделения памяти (`new`, `malloc`).
  - **Особенности**: Управляется программистом **вручную** (выделение и освобождение). Если не освободить, возникнет **утечка памяти** (Memory Leak).
  - **Производительность**: Очень большой размер (ограничен физической/виртуальной памятью), но медленнее стека. Частые аллокации ведут к **фрагментации памяти**.

### 3. 全局/静态存储区 / Глобальная/Статическая область (Global/Static)

- **中文**:
  - **用途**: 存储全局变量 (`global`) 和静态变量 (`static`)。
  - **特点**: 变量在程序**整个运行期间**都存在，直到程序结束才被释放。
  - **细分**:
    - **已初始化区 (.data)**: 存放已赋初值的全局/静态变量。
    - **未初始化区 (.bss)**: 存放未赋初值的变量（默认自动初始化为 0）。
- **Русский**:
  - **Назначение**: Хранит глобальные переменные и статические переменные (`static`).
  - **Особенности**: Переменные живут **в течение всего времени выполнения** программы и освобождаются только при её завершении.
  - **Подразделы**:
    - **Инициализированная (.data)**: Переменные с начальным значением.
    - **Неинициализированная (.bss)**: Переменные без начального значения (автоматически обнуляются).

### 4. 常量存储区 / Область констант (Constant Storage)

- **中文**:
  - **用途**: 存储常量数据，如字符串字面量 (`"Hello"`) 和 `const` 修饰的全局变量。
  - **特点**: 这块内存是**只读**的 (Read-only)。试图修改会导致运行时错误 (Segmentation Fault)。
- **Русский**:
  - **Назначение**: Хранит константные данные, такие как строковые литералы (`"Hello"`) и глобальные переменные с `const`.
  - **Особенности**: Эта память **только для чтения**. Попытка изменения приведет к ошибке времени выполнения (Segmentation Fault).

### 5. 代码区 / Сегмент кода (Code/Text Segment)

- **中文**:
  - **用途**: 存储程序的二进制代码（函数体的机器指令）。
  - **特点**: 也是只读的，防止程序意外修改指令。
- **Русский**:
  - **Назначение**: Хранит бинарный код программы (машинные инструкции функций).
  - **Особенности**: Также только для чтения, чтобы предотвратить случайное изменение инструкций программой.

------

### 对比总结 / Сравнительная таблица

| **特性 / Свойство**           | **栈 (Stack)**       | **堆 (Heap)**           | **全局/静态 (Global/Static)**   |
| ----------------------------- | -------------------- | ----------------------- | ------------------------------- |
| **管理方式 / Управление**     | 自动 (Compiler)      | 手动 (Programmer)       | 自动 (OS/Runtime)               |
| **生命周期 / Жизненный цикл** | 函数作用域内 / Scope | 直到被释放 / Until free | 程序运行期间 / Program lifetime |
| **大小 / Размер**             | 小 (MBs)             | 大 (GBs)                | 固定 / Fixed                    |
| **分配速度 / Скорость**       | 极快 / Very Fast     | 较慢 / Slow             | 启动时分配 / At startup         |

### 代码示例 / Пример кода

C++

```c
#include <iostream>

int globalVar = 1;        // Global/Static (.data)
const int constVar = 100; // Constant area

int main() {
    static int staticVar = 2; // Global/Static (.data)
    int localVar = 3;         // Stack
    
    // "Hello" lives in Constant area
    // ptr lives in Stack
    // The memory ptr points to lives in Heap
    int* ptr = new int(4);    

    delete ptr;
    return 0;
}
```
