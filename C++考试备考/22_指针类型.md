## 题目 / Вопрос

- **中文**：在 C 或 C++ 中，有哪些种类的指针类型？  
- **俄文**: Какие бывают типы указателей в C или в C++?

C/C++ 中的指针类型非常丰富。我们可以将它们粗略地分为 **原始指针 (Raw Pointers)** 和 C++ 特有的 **智能指针 (Smart Pointers)**。

以下是中俄互译的详细分类：

------

### 一、 原始指针 (Raw Pointers / Сырые указатели)

这是 C 和 C++ 共有的基础类型，直接操作内存地址。

(Это базовые типы, общие для C и C++, работающие напрямую с адресами памяти.)

#### 1. 普通指针 (Typed Pointer / Типизированный указатель)

- **Syntax**: `int* p;`, `char* str;`
- **中文**：最基本的指针，指向特定类型的变量。通过解引用 (`*p`) 可以获取该地址的值。
- **Русский**：Самый базовый указатель, указывающий на переменную определенного типа. Разыменование (`*p`) позволяет получить значение по этому адресу.

#### 2. 通用指针 (Void Pointer / Указатель типа void)

- **Syntax**: `void* p;`
- **中文**：也叫“无类型指针”。它可以指向任何类型的数据，但在强制类型转换之前，**不能被解引用**，也不能进行指针算术运算。
- **Русский**：Также называется «беступиковым указателем». Он может указывать на данные любого типа, но его **нельзя разыменовывать** или использовать в адресной арифметике до явного приведения типа.

#### 3. 空指针 (Null Pointer / Нулевой указатель)

- **Syntax**: `int* p = NULL;` (C), `int* p = nullptr;` (C++11)
- **中文**：指向地址 `0` 的指针，表示“不指向任何有效对象”。在 C++ 中，强烈建议使用 `nullptr` 替代 `NULL` 以获得类型安全。
- **Русский**：Указатель на адрес `0`, означающий «не указывает ни на какой валидный объект». В C++ настоятельно рекомендуется использовать `nullptr` вместо `NULL` для безопасности типов.

#### 4. 函数指针 (Function Pointer / Указатель на функцию)

- **Syntax**: `void (*funcPtr)(int);`
- **中文**：指向代码段中函数入口地址的指针。用于实现回调函数 (Callback)。
- **Русский**：Указатель на адрес начала функции в сегменте кода. Используется для реализации функций обратного вызова (Callback).

------

### 二、 const 限定的指针 (Const-qualified Pointers / Указатели с квалификатором const)

这是一个常见的面试考点，主要区别在于 const 的位置。

(Это популярный вопрос на собеседованиях. Главное отличие — положение const.)

| **写法 (Синтаксис)** | **中文名称 (Китайский)** | **俄文名称 (Русский)**                 | **含义 (Значение)**                                          |
| -------------------- | ------------------------ | -------------------------------------- | ------------------------------------------------------------ |
| `const int* p`       | **指向常量的指针**       | **Указатель на константу**             | 指针可变，数据不可变。 (Адрес менять можно, данные — нельзя.) |
| `int* const p`       | **常量指针**             | **Константный указатель**              | 指针不可变，数据可变。 (Адрес менять нельзя, данные — можно.) |
| `const int* const p` | **指向常量的常量指针**   | **Константный указатель на константу** | 指针和数据都不可变。 (Ничего менять нельзя.)                 |

------

### 三、 智能指针 (Smart Pointers / Умные указатели)

这是 C++ 标准库 (<memory>) 特有的，用于自动管理内存，防止内存泄漏。C 语言没有这些。

(Специфичны для стандартной библиотеки C++ (<memory>), используются для автоматического управления памятью и предотвращения утечек. В языке C их нет.)

#### 1. `std::unique_ptr`

- **中文**：**独占所有权**。同一时间只能有一个指针指向该对象。不可复制，只能移动 (`std::move`)。
- **Русский**：**Эксклюзивное владение**. На объект может указывать только один указатель. Нельзя копировать, можно только перемещать (`std::move`).

#### 2. `std::shared_ptr`

- **中文**：**共享所有权**。内部维护一个引用计数 (Reference Count)。当计数归零时，自动释放内存。
- **Русский**：**Разделяемое владение**. Внутри поддерживает счетчик ссылок. Память освобождается автоматически, когда счетчик достигает нуля.

#### 3. `std::weak_ptr`

- **中文**：**弱引用**。配合 `shared_ptr` 使用，不增加引用计数。主要用于解决“循环引用”导致的内存泄漏问题。
- **Русский**：**Слабая ссылка**. Работает в паре с `shared_ptr`, не увеличивает счетчик ссылок. В основном используется для решения проблемы утечки памяти из-за «циклических ссылок».

------

### 四、 危险状态 (Опасные состояния)

严格来说这不是“类型”，而是指针的某种糟糕状态。

(Строго говоря, это не «типы», а плохие состояния указателей.)

1. **野指针 (Wild Pointer / Дикий указатель)**:
   - 未初始化的指针，指向随机内存。
   - (Неинициализированный указатель, указывающий на случайную память.)
2. **悬空指针 (Dangling Pointer / Висячий указатель)**:
   - 指向的内存已经被释放 (`free/delete`)，但指针本身没有置空。
   - (Память была освобождена (`free/delete`), но сам указатель не был обнулен.)
