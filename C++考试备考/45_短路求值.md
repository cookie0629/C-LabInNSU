## 题目 / Вопрос

- **中文**：在 C++ 中，什么是“短路求值”（short-circuiting）？  
- **俄文**: Что такое «short-circuiting» в C++?

**短路求值（Short-Circuit Evaluation）** 是 C++ 中逻辑运算符 `&&`（逻辑与）和 `||`（逻辑或）的一种优化行为。

**Сокращённое вычисление (Short-Circuit Evaluation)** — это оптимизационное поведение логических операторов `&&` (логическое И) и `||` (логическое ИЛИ) в C++.

------

### 1. 核心机制 / Основной механизм

当计算一个逻辑表达式时，如果**左侧的操作数已经能够确定整个表达式的结果**，那么**右侧的操作数将不再被执行**。

При вычислении логического выражения, если **левый операнд уже определяет результат всего выражения**, то **правый операнд не будет выполняться**.

#### **A. 逻辑与 / Логическое И (`&&`)**

- **规则**: `expression1 && expression2`
- **中文**: 如果 `expression1` 为 **false**，则整个表达式一定为 false。此时，`expression2` **完全不会被执行**。
- **Русский**: Если `expression1` равно **false**, то всё выражение гарантированно false. В этом случае `expression2` **вообще не выполняется**.

#### **B. 逻辑或 / Логическое ИЛИ (`||`)**

- **规则**: `expression1 || expression2`
- **中文**: 如果 `expression1` 为 **true**，则整个表达式一定为 true。此时，`expression2` **完全不会被执行**。
- **Русский**: Если `expression1` равно **true**, то всё выражение гарантированно true. В этом случае `expression2` **вообще не выполняется**.

------

### 2. 重要应用场景：安全性 / Важное применение: Безопасность

最典型的用途是**防止空指针解引用**。

Самый типичный случай использования — **защита от разыменования нулевого указателя**.

C++

```
// Safe check
if (ptr != nullptr && ptr->value == 10) {
    // ...
}
```

- **中文**: 如果 `ptr` 是空指针（`false`），右边的 `ptr->value` 永远不会执行，从而避免了程序崩溃。
- **Русский**: Если `ptr` нулевой (`false`), правая часть `ptr->value` никогда не выполнится, что предотвращает падение программы.

------

### 3. 陷阱：操作符重载 / Ловушка: Перегрузка операторов

- **中文**: 如果你重载了 `&&` 或 `||` 操作符，**短路特性将会丢失**。它们会变成普通的函数调用，导致两个参数都会被计算。因此，C++ 最佳实践**强烈不建议**重载这两个操作符。
- **Русский**: Если вы перегрузите операторы `&&` или `||`, **свойство сокращённого вычисления пропадает**. Они становятся обычными вызовами функций, где вычисляются оба аргумента. Поэтому лучшие практики C++ **настоятельно не рекомендуют** перегружать эти операторы.

------

### 代码示例 / Пример кода

C++

```c
#include <iostream>

bool checkFirst() {
    std::cout << "Checking First..." << std::endl;
    return false;
}

bool checkSecond() {
    std::cout << "Checking Second..." << std::endl; // Won't print in AND case
    return true;
}

int main() {
    // 1. AND Short-circuit
    // 因为 checkFirst() 返回 false，checkSecond() 被跳过
    // Так как checkFirst() вернул false, checkSecond() пропускается
    if (checkFirst() && checkSecond()) {
        std::cout << "Both true";
    }

    std::cout << "\n----------------\n";

    int* ptr = nullptr;
    // 2. Safety usage
    // 如果没有短路求值，这里会崩溃
    // Без сокращённого вычисления здесь был бы крэш
    if (ptr && *ptr == 5) { 
        std::cout << "This won't execute";
    } else {
        std::cout << "Safe! Pointer was null.";
    }

    return 0;
}
```
