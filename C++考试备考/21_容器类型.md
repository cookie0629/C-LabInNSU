## 题目 / Вопрос

- **中文**：C++ 中有哪些类型的容器？请给出每类容器的代表例子。  
- **俄文**: Какие бывают типы контейнеров в C++? Назовите представителей каждого типа контейнеров?

C++ 标准模板库 (STL) 中的容器主要分为 **四大类**。每种类型都有不同的底层数据结构和适用场景。

以下是中俄互译的详细分类：

------

### 1. 序列容器 (Sequence Containers / Последовательные контейнеры)

- **定义 (Определение)**:
  - **中文**：数据像线性列表一样排列。元素的顺序取决于程序员插入的顺序，与元素的值无关。
  - **Русский**：Данные организованы линейно. Порядок элементов зависит от того, как программист их вставил, и не зависит от значения элементов.
- **代表例子 (Представители)**:
  - **`std::vector`**:
    - **中文**：动态数组。支持快速随机访问（`O(1)`），但在中间插入/删除元素较慢。**这是最常用的默认容器**。
    - **Русский**：Динамический массив. Быстрый произвольный доступ (`O(1)`), но медленная вставка/удаление в середине. **Это контейнер по умолчанию.**
  - **`std::list`**:
    - **中文**：双向链表。在任何位置插入/删除都很快（`O(1)`），但不支持随机访问。
    - **Русский**：Двусвязный список. Быстрая вставка/удаление везде (`O(1)`), но нет произвольного доступа.
  - **`std::deque`**:
    - **中文**：双端队列。头尾插入都很块。
    - **Русский**：Двусторонняя очередь. Быстрая вставка с обоих концов.

------

### 2. 关联容器 (Associative Containers / Ассоциативные контейнеры)

- **定义 (Определение)**:
  - **中文**：基于 **红黑树 (Red-Black Tree)** 实现。元素会根据键值（Key）**自动排序**。查找时间复杂度通常为 `O(log n)`。
  - **Русский**：Реализованы на основе **красно-черных деревьев**. Элементы **автоматически сортируются** по ключу. Сложность поиска обычно `O(log n)`.
- **代表例子 (Представители)**:
  - **`std::set`**:
    - **中文**：集合。只包含唯一的 Key，自动排序去重。
    - **Русский**：Множество. Содержит только уникальные ключи, автоматически сортирует.
  - **`std::map`**:
    - **中文**：映射（字典）。存储 `Key-Value` 对，按 Key 排序。
    - **Русский**：Словарь (отображение). Хранит пары `Key-Value`, отсортированные по ключу.
  - **`std::multiset` / `std::multimap`**:
    - **中文**：允许 Key 重复的版本。
    - **Русский**：Версии, допускающие дублирование ключей.

------

### 3. 无序关联容器 (Unordered Associative Containers / Неупорядоченные ассоциативные контейнеры)

- **定义 (Определение)**:
  - **C++11 引入**。基于 **哈希表 (Hash Table)** 实现。
  - **中文**：元素也是 `Key-Value` 形式，但**没有顺序**。平均查找速度非常快，接近 `O(1)`。
  - **Русский**：**Введено в C++11**. Реализовано на основе **хэш-таблиц**. Элементы также в формате `Key-Value`, но **без порядка**. Средняя скорость поиска очень высока, близка к `O(1)`.
- **代表例子 (Представители)**:
  - **`std::unordered_map`**: 哈希映射 (Хэш-мап).
  - **`std::unordered_set`**: 哈希集合 (Хэш-сет).

------

### 4. 容器适配器 (Container Adapters / Адаптеры контейнеров)

- **定义 (Определение)**:
  - **中文**：它们不是独立的容器，而是对序列容器（如 `deque` 或 `vector`）的**包装**，限制了接口以实现特定的数据结构逻辑（如先进先出）。
  - **Русский**：Это не самостоятельные контейнеры, а **обертки** над последовательными контейнерами (например, `deque` или `vector`), ограничивающие интерфейс для реализации конкретной логики (например, FIFO).
- **代表例子 (Представители)**:
  - **`std::stack`**: 栈 (LIFO - Last In First Out / Стек).
  - **`std::queue`**: 队列 (FIFO - First In First Out / Очередь).
  - **`std::priority_queue`**: 优先队列 (总是最大的元素先出 / Приоритетная очередь).

### 总结 (Резюме)

| **类别 (Категория)** | **核心特性 (Особенность)**               | **代表 (Примеры)**               |
| -------------------- | ---------------------------------------- | -------------------------------- |
| **Sequence**         | 线性，保持插入顺序 (Linear, keeps order) | `vector`, `list`, `deque`        |
| **Associative**      | 排序树，O(log n) (Sorted Tree)           | `map`, `set`                     |
| **Unordered**        | 哈希表，O(1) (Hash Table)                | `unordered_map`, `unordered_set` |
| **Adapters**         | 受限接口 (Restricted Interface)          | `stack`, `queue`                 |
