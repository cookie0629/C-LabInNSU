## 题目 / Вопрос

- **中文**：什么是 Lambda 表达式？它在 C++ 中是如何实现的？  
- **俄文**: Что такое лямбда-выражение? Как оно реализовано в C++?

**Lambda 表达式 (Lambda Expression)** 是 C++11 引入的最重要的特性之一。它允许你在需要的地方“就地”定义匿名函数对象。

**Лямбда-выражение (Lambda Expression)** — это одна из важнейших возможностей, введенных в C++11. Она позволяет определять анонимные функциональные объекты «на месте», именно там, где они нужны.

------

### 1. 什么是 Lambda 表达式？ / Что такое лямбда-выражение?

它本质上是**语法糖 (Syntactic Sugar)**。它允许你写出非常简洁的代码来创建函数对象，而不需要显式编写一个完整的类。

По сути, это **синтаксический сахар**. Он позволяет писать очень лаконичный код для создания функциональных объектов без необходимости явного написания полного класса.

基本语法 / Базовый синтаксис:

[captures](params) -> return_type { body }

1. **`[captures]`**: 捕获列表。定义外部变量如何传递给 Lambda（传值 `=` 或传引用 `&`）。
   - *RU: Список захвата. Определяет, как внешние переменные передаются в лямбду (по значению `=` или по ссылке `&`).*
2. **`(params)`**: 参数列表。就像普通函数的参数。
   - *RU: Список параметров. Как у обычной функции.*
3. **`-> return_type`**: 返回类型（可选，通常编译器能自动推导）。
   - *RU: Тип возврата (необязательно, обычно выводится компилятором).*
4. **`{ body }`**: 函数体。
   - *RU: Тело функции.*

------

### 2. 它是如何实现的？ / Как оно реализовано?

这是面试中的高频考点。Lambda **不是**神奇的魔法，编译器在后台默默为你做了一件事：**生成一个类**。

Это частый вопрос на собеседованиях. Лямбда — **не** магия, компилятор просто тихо делает за вас одну вещь в фоновом режиме: **генерирует класс**.

#### **机制流程 / Механизм**:

1. **生成类 / Генерация класса**: 编译器会生成一个具有唯一名称的、匿名的类（称为闭包类型，Closure Type）。
   - *RU*: Компилятор генерирует анонимный класс с уникальным именем (называемый типом замыкания).
2. **成员变量 / Члены-переменные**: 捕获列表 `[]` 中的变量，会被转换成这个类的**私有成员变量**。
   - *RU*: Переменные из списка захвата `[]` превращаются в **приватные члены** этого класса.
3. **重载调用符 / Перегрузка вызова**: Lambda 的函数体 `{...}` 会被转换成该类的 **`operator()`** 的实现。
   - *RU*: Тело лямбды `{...}` превращается в реализацию **`operator()`** этого класса.
4. **Const 属性 / Свойство Const**: 默认情况下，生成的 `operator()` 是 `const` 的。如果你想修改按值捕获的变量，必须加上 `mutable` 关键字。
   - *RU*: По умолчанию сгенерированный `operator()` является `const`. Если вы хотите изменять переменные, захваченные по значению, нужно добавить ключевое слово `mutable`.

### 代码解剖 (编译器视角) / Разбор кода (Взгляд компилятора)

让我们看看你写的代码，以及编译器生成的代码。

Давайте посмотрим на код, который пишете вы, и код, который генерирует компилятор.

#### **A. 你写的代码 / Ваш код**

C++

```c
int factor = 10;
// Lambda capturing 'factor' by value
// 按值捕获 factor 的 Lambda
auto multiplier = [factor](int n) {
    return n * factor;
};

int result = multiplier(5); // 50
```

#### **B. 编译器生成的代码 (伪代码) / Код от компилятора (Псевдокод)**

C++

```c
// 1. Compiler generates a unique class
// 1. 编译器生成唯一类
class __lambda_unique_name_1 {
private:
    int m_factor; // Captured variable becomes member

public:
    // Constructor initializes the capture
    // 构造函数初始化捕获的变量
    __lambda_unique_name_1(int f) : m_factor(f) {}

    // 2. The body becomes operator()
    // 默认是 const，除非 lambda 声明为 mutable
    // 2. Тело становится operator()
    // По умолчанию const, если лямбда не объявлена как mutable
    int operator()(int n) const {
        return n * m_factor;
    }
};

// Main logic translation
int factor = 10;
// Create instance of the closure type
auto multiplier = __lambda_unique_name_1(factor); 

int result = multiplier.operator()(5); 
```

### 3. `mutable` 的作用 / Роль `mutable`

如果你在 Lambda 中按值捕获了一个变量，默认是不能修改它的，因为 `operator()` 是 `const` 的。

Если вы захватили переменную по значению, по умолчанию ее нельзя изменять, так как `operator()` является `const`.

C++

```
int x = 0;
// auto f = [x]() { x++; }; // ❌ Error: assignment of read-only variable
auto f = [x]() mutable { x++; }; // ✅ OK: operator() is no longer const
```

### 总结 / Резюме

- Lambda 仅仅是**仿函数（Functor）**的语法糖。
- **捕获** = 类的**成员变量**初始化。
- **函数体** = **`operator()`** 的实现。
- Лямбда — это просто синтаксический сахар для **функтора**.
- **Захват** = Инициализация **членов класса**.
- **Тело** = Реализация **`operator()`**.
