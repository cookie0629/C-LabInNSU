## 题目 / Вопрос

- **中文**：什么是 C++ 中的“类型擦除（type erasure）”惯用法？它是如何实现的？请举出使用该惯用法的标准库类。  
- **俄文**: Что такое и как реализуется идиома стирания типа в C++? Назовите классы стандартной библиотеки, которые используют данную идиому.

**类型擦除（Type Erasure）** 是 C++ 中一种强大的设计模式（惯用法）。它允许你在不丢失类型安全性的前提下，将不同类型的对象存储在同一个容器或变量中，并对外提供统一的接口。

**Стирание типа (Type Erasure)** — это мощный паттерн проектирования (идиома) в C++. Он позволяет хранить объекты различных типов в одном контейнере или переменной, сохраняя типобезопасность и предоставляя единый внешний интерфейс.

它本质上是**模板（静态多态）**与**虚函数（动态多态）**的混合体。

По сути, это гибрид **шаблонов (статический полиморфизм)** и **виртуальных функций (динамический полиморфизм)**.

------

### 1. 它是如何实现的？ / Как это реализуется?

实现类型擦除通常需要三个层次的类结构：

Реализация стирания типа обычно требует трехуровневой структуры классов:

1. **外部封装类 (Wrapper)**: 一个普通类（非模板），用户直接使用它。它持有一个指向“概念基类”的指针。
   - *RU: Внешняя обертка (Wrapper)*: Обычный класс (не шаблон), который использует пользователь. Хранит указатель на «базовый класс концепции».
2. **内部抽象基类 (Concept)**: 定义了统一的接口（纯虚函数）。
   - *RU: Внутренний абстрактный базовый класс (Concept)*: Определяет единый интерфейс (чисто виртуальные функции).
3. **内部模板子类 (Model)**: 继承自 Concept。这是一个模板类，它保存实际的具体类型 `T` 的数据，并实现虚函数，将调用转发给 `T`。
   - *RU: Внутренний шаблонный подкласс (Model)*: Наследуется от Concept. Это шаблонный класс, который хранит данные конкретного типа `T` и реализует виртуальные функции, перенаправляя вызовы к `T`.

### 2. 代码示例 / Пример кода

让我们实现一个简单的类型擦除类 `AnyPrintable`，它可以存储任何拥有 `print()` 方法的对象。

Реализуем простой класс со стиранием типа `AnyPrintable`, который может хранить любой объект, имеющий метод `print()`.

C++

```c
#include <iostream>
#include <memory>
#include <string>
#include <vector>

// 1. External Wrapper / 外部封装类
class AnyPrintable {
private:
    // 2. Internal Abstract Base (Concept) / 内部抽象基类
    struct Concept {
        virtual ~Concept() {}
        virtual void print() const = 0;
    };

    // 3. Internal Template Derived (Model) / 内部模板子类
    template <typename T>
    struct Model : Concept {
        T data;
        Model(T x) : data(std::move(x)) {}
        void print() const override {
            data.print(); // Forward call to concrete type
        }
    };

    std::unique_ptr<Concept> ptr;

public:
    // Templated Constructor / 模板构造函数
    // 这里的 T 被擦除了 / Здесь T стирается
    template <typename T>
    AnyPrintable(T x) : ptr(std::make_unique<Model<T>>(x)) {}

    void print() const {
        ptr->print();
    }
};

// Usage Classes / Классы для использования
struct Foo {
    void print() const { std::cout << "I am Foo" << std::endl; }
};

struct Bar {
    void print() const { std::cout << "I am Bar" << std::endl; }
};

int main() {
    std::vector<AnyPrintable> vec;
    
    // Storing different types in the same vector!
    // Хранение разных типов в одном векторе!
    vec.emplace_back(Foo{});
    vec.emplace_back(Bar{});

    for (const auto& item : vec) {
        item.print();
    }

    return 0;
}
```

Следующие компоненты стандартной библиотеки используют стирание типа:

1. **`std::function<Sig>`**
   - **中文**: 可以存储任何“可调用对象”（函数指针、Lambda、仿函数），只要签名匹配。具体的调用机制被擦除了。
   - **Русский**: Может хранить любой «вызываемый объект» (указатель на функцию, лямбда, функтор), если сигнатура совпадает. Конкретный механизм вызова стерт.
2. **`std::any` (C++17)**
   - **中文**: 可以存储任何类型的单一值。它是类型安全的 `void*` 替代品。
   - **Русский**: Может хранить единственное значение любого типа. Это типобезопасная альтернатива `void*`.
3. **`std::shared_ptr<T>` (Deleter)**
   - **中文**: 虽然 `T` 是固定的，但 `shared_ptr` 的**删除器（Deleter）** 是类型擦除的。你可以传递任何可调用的删除逻辑，而不会改变 `shared_ptr` 的类型。
   - **Русский**: Хотя `T` фиксирован, **удалитель (Deleter)** в `shared_ptr` реализован через стирание типа. Вы можете передать любую логику удаления, не меняя тип самого `shared_ptr`.
