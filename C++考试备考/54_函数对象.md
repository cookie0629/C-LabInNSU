## 题目 / Вопрос

- **中文**：什么是 C++ 中的“函数对象”（仿函数）？它是如何实现的？你知道标准库中哪些函数对象？  
- **俄文**: Что такое и как реализуются функциональные объекты в C++? Какие функциональные объекты, представленные в стандартной библиотеке вы знаете?

**函数对象（Function Object）**，通常被称为**仿函数（Functor）**，是 C++ 中一种强大的编程技术。

**Функциональный объект**, часто называемый **функтором (Functor)** — это мощная техника программирования в C++.

------

### 1. 什么是仿函数？如何实现？ / Что такое функтор и как он реализован?

- **定义 / Определение**:
  - **中文**: 仿函数是一个**类（或结构体）的实例**，但它可以像普通函数一样被调用。
  - **Русский**: Это **экземпляр класса (или структуры)**, который можно вызывать как обычную функцию.
- **实现机制 / Механизм реализации**:
  - **中文**: 通过在类中重载**函数调用运算符 `operator()`** 来实现。
  - **Русский**: Реализуется путем перегрузки **оператора вызова функции `operator()`** внутри класса.
- **核心优势 / Главное преимущество**:
  - **状态 (State)**: 普通函数是无状态的，但仿函数可以拥有成员变量，因此它可以**“记住”信息**（例如累加器、阈值）。
  - **性能 (Performance)**: 编译器通常能将仿函数**内联（Inline）**，而普通函数指针很难被内联。
  - **Состояние**: Обычные функции не имеют состояния, а функторы могут иметь переменные-члены, поэтому они могут **«запоминать» информацию** (например, аккумулятор или порог).
  - **Производительность**: Компиляторы часто могут **встраивать (inline)** функторы, тогда как указатели на функции встроить сложнее.

------

### 2. 标准库中的常见仿函数 / Функторы в стандартной библиотеке

它们大多定义在 <functional> 头文件中。

Большинство из них определены в заголовке <functional>.

#### **A. 算术类 / Арифметические**

- `std::plus<T>`: 执行 `x + y`。
- `std::minus<T>`: 执行 `x - y`。
- `std::multiplies<T>`: 执行 `x * y`。

#### **B. 比较类 / Сравнения**

- `std::less<T>`: 执行 `x < y`。这是 `std::sort`、`std::map`、`std::set` 的默认排序规则。
- `std::greater<T>`: 执行 `x > y`。用于降序排序。
- `std::equal_to<T>`: 执行 `x == y`。

#### **C. 逻辑类 / Логические**

- `std::logical_and<T>`: 执行 `x && y`。
- `std::logical_not<T>`: 执行 `!x`。

### 代码示例 / Пример кода

这个例子展示了如何创建一个**带有状态**的仿函数，这在普通函数中很难通过非全局变量实现。

Этот пример показывает, как создать функтор **с состоянием**, что трудно реализовать с обычной функцией без глобальных переменных.

C++

```c
#include <iostream>
#include <vector>
#include <algorithm>
#include <functional> // for std::greater

// 1. Custom Functor Definition
// 自定义仿函数：拥有状态 (threshold)
// Пользовательский функтор: имеет состояние (threshold)
class PrintIfGreaterThan {
    int threshold; // State / 状态
public:
    PrintIfGreaterThan(int val) : threshold(val) {}

    // Overloading operator()
    // 重载调用运算符
    void operator()(int x) const {
        if (x > threshold) {
            std::cout << x << " ";
        }
    }
};

int main() {
    std::vector<int> numbers = {10, 5, 20, 3, 100, 50};

    // 2. Using Custom Functor
    // 使用自定义仿函数，打印所有大于 15 的数
    // Используем функтор, печатаем все числа больше 15
    std::cout << "Numbers > 15: ";
    
    // 我们实例化了一个对象，并将其像函数一样传递
    // Мы создаем экземпляр объекта и передаем его как функцию
    PrintIfGreaterThan printer(15); 
    std::for_each(numbers.begin(), numbers.end(), printer);
    std::cout << std::endl;

    // 3. Using Standard Library Functor
    // 使用标准库仿函数进行降序排序
    // Используем стандартный функтор для сортировки по убыванию
    std::sort(numbers.begin(), numbers.end(), std::greater<int>());

    std::cout << "Sorted Descending: ";
    for(int n : numbers) std::cout << n << " "; // 100 50 20 10 5 3

    return 0;
}
```

### 补充知识：Lambda 表达式 / Дополнение: Лямбда-выражения

**中文**: C++11 引入的 Lambda 表达式实际上就是**匿名仿函数**的语法糖。编译器在后台会自动为你生成一个重载了 `operator()` 的类。

**Русский**: Лямбда-выражения, введенные в C++11, по сути являются синтаксическим сахаром для **анонимных функторов**. Компилятор автоматически генерирует для вас класс с перегруженным `operator()`.
