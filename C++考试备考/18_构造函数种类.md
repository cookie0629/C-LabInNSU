## 题目 / Вопрос

- **中文**：C++ 中有哪些种类的构造函数？每一种构造函数的用途是什么？  
- **俄文**: Какие бывают виды конструкторов в C++? Для чего предназначен каждый вид?

在 C++ 中，构造函数主要分为 **四种核心类型**。每一种都在对象生命周期的不同阶段扮演关键角色。

以下是中俄互译的详细分类与用途：

------

### 1. 默认构造函数 (Default Constructor / Конструктор по умолчанию)

- **特征 (Характеристика)**:
  - 不需要任何参数（或者所有参数都有默认值）。
  - (Не требует аргументов или все аргументы имеют значения по умолчанию.)
- **用途 (Назначение)**:
  - **中文**：用于创建一个“空”对象或将其初始化为默认状态。如果你没有定义任何构造函数，编译器会自动为你生成一个。
  - **Русский**：Используется для создания «пустого» объекта или инициализации его состоянием по умолчанию. Если вы не определите ни одного конструктора, компилятор сгенерирует его автоматически.
- **Syntax**: `MyClass();`

------

### 2. 带参构造函数 (Parameterized Constructor / Параметризованный конструктор)

- **特征 (Характеристика)**:
  - 接收一个或多个参数。
  - (Принимает один или несколько аргументов.)
- **用途 (Назначение)**:
  - **中文**：允许在创建对象时直接赋予它具体的数据值。
  - **Русский**：Позволяет присвоить объекту конкретные данные непосредственно при его создании.
- **Syntax**: `MyClass(int a, float b);`

------

### 3. 拷贝构造函数 (Copy Constructor / Конструктор копирования)

- **特征 (Характеристика)**:
  - 参数是同类对象的**常量引用** (`const T&`)。
  - (Аргумент — **константная ссылка** на объект того же класса (`const T&`).)
- **用途 (Назначение)**:
  - **中文**：用于从一个已存在的对象**克隆**出一个新对象。通常在“按值传递”参数或返回对象时被调用。
  - **Русский**：Используется для **клонирования** нового объекта из уже существующего. Обычно вызывается при передаче аргументов «по значению» или возврате объекта.
- **Syntax**: `MyClass(const MyClass& other);`

------

### 4. 移动构造函数 (Move Constructor / Конструктор перемещения)

- **特征 (Характеристика)**:
  - **C++11 新特性**。参数是同类对象的**右值引用** (`T&&`)。
  - (**Нововведение C++11**. Аргумент — **r-value ссылка** на объект того же класса (`T&&`).)
- **用途 (Назначение)**:
  - **中文**：用于从临时对象（即将销毁的对象）中**“窃取”**资源（如堆内存指针），而不是进行昂贵的深度拷贝。这是现代 C++ 性能优化的关键。
  - **Русский**：Используется для **«кражи»** ресурсов (например, указателей на кучу) у временного объекта (который скоро будет уничтожен) вместо дорогостоящего глубокого копирования. Это ключ к оптимизации производительности в современном C++.
- **Syntax**: `MyClass(MyClass&& other);`

------

### 代码示例 (Пример кода)

C++

```c
#include <iostream>
#include <utility> // for std::move

class Widget {
private:
    int* data;
public:
    // 1. 默认构造函数 (Default)
    Widget() : data(new int(0)) { 
        std::cout << "Default Constructor\n"; 
    }

    // 2. 带参构造函数 (Parameterized)
    Widget(int val) : data(new int(val)) { 
        std::cout << "Parameterized Constructor\n"; 
    }

    // 3. 拷贝构造函数 (Copy)
    // 深拷贝：分配新内存并复制值 (Deep Copy)
    Widget(const Widget& other) : data(new int(*other.data)) {
        std::cout << "Copy Constructor\n";
    }

    // 4. 移动构造函数 (Move)
    // 窃取指针，不分配新内存 (Steal pointer)
    Widget(Widget&& other) noexcept : data(other.data) {
        other.data = nullptr; //以此确保析构函数不会释放同一块内存
        std::cout << "Move Constructor\n";
    }

    ~Widget() { delete data; }
};

int main() {
    Widget w1(10);          // Parameterized
    Widget w2 = w1;         // Copy
    Widget w3 = std::move(w1); // Move
    return 0;
}
```

### 总结表 (Сводная таблица)

| **类型 (Тип)**    | **参数形式 (Аргумент)** | **核心行为 (Действие)**                 |
| ----------------- | ----------------------- | --------------------------------------- |
| **Default**       | `()`                    | 初始化默认值 (Init defaults)            |
| **Parameterized** | `(Args...)`             | 初始化特定值 (Init specific values)     |
| **Copy**          | `(const T&)`            | **复制**资源 (Duplicate/Clone resource) |
| **Move**          | `(T&&)`                 | **转移**所有权 (Transfer ownership)     |



**扩展:  五法则的核心思想**：资源管理的一致性。

当你需要**自定义析构函数**来释放资源时，通常也需要**自定义拷贝操作**（深拷贝）或**禁用拷贝操作**，同时还要考虑**移动操作**以获得最佳性能。

**现代 C++ 中**，优先使用 RAII 和智能指针，可以避免手动实现五法则，让代码更安全、更简洁。
