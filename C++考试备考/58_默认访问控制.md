## 题目 / Вопрос

- **中文**：什么是“默认访问控制区段”（默认的 `public`/`private`）？对于不同的用户自定义类型，它有哪些不同的特点？  
- **俄文**: Что такое секция доступа по умолчанию? В чем её особенность для разных пользовательских типов данных?

在 C++ 中，“默认访问控制”指的是当你没有显式写出 `public:`、`private:` 或 `protected:` 标签时，编译器默认赋予成员变量或基类的访问权限。

В C++ «контроль доступа по умолчанию» означает уровень доступа, который компилятор присваивает переменным-членам или базовым классам, если вы явно не написали метки `public:`, `private:` или `protected:`.

这是 class 和 struct 之间唯一的技术区别。

Это единственное техническое различие между class и struct.

------

### 1. 成员的默认访问权限 / Доступ к членам по умолчанию

这是最直观的区别，决定了类内部定义的变量一开始是对外可见的还是隐藏的。

Это самое очевидное различие, определяющее, видны ли переменные, определенные внутри, снаружи или скрыты.

| **类型 / Тип** | **默认权限 / Доступ по умолчанию** | **哲学原因 / Философия**                                     |
| -------------- | ---------------------------------- | ------------------------------------------------------------ |
| **`class`**    | **`private`** (私有)               | 面向对象核心是**封装**。默认隐藏数据，只暴露接口。   ООП базируется на **инкапсуляции**. Скрывать данные, открывать интерфейс. |
| **`struct`**   | **`public`** (公有)                | 为了兼容 **C 语言**。C 中的结构体是对外完全开放的数据包。   Для совместимости с **C**. Структуры в C — это полностью открытые пакеты данных. |
| **`union`**    | **`public`** (公有)                | 同样为了兼容 C 语言。   Также для совместимости с C.         |

### 2. 继承的默认访问权限 / Доступ при наследовании по умолчанию

这是经常被忽视的第二个区别。当你继承另一个类但没有指定继承方式时（如 : Base 而不是 : public Base）：

Это второе отличие, которое часто упускают из виду. Когда вы наследуете другой класс, но не указываете тип наследования (например, : Base вместо : public Base):

| **类型 / Тип** | **语法示例 / Пример синтаксиса** | **默认继承方式 / Наследование по умолчанию** |
| -------------- | -------------------------------- | -------------------------------------------- |
| **`class`**    | `class Derived : Base`           | **`private`** inheritance                    |
| **`struct`**   | `struct Derived : Base`          | **`public`** inheritance                     |

------

### 代码示例 / Пример кода

C++

```c
#include <iostream>

// 1. CLASS: Default is private
class MyClass {
    int x; // 默认是 private / По умолчанию private
public:
    MyClass() : x(0) {}
};

// 2. STRUCT: Default is public
struct MyStruct {
    int y; // 默认是 public / По умолчанию public
};

// 3. Inheritance Defaults
class Base {};

class DerivedClass : Base {};   // = : private Base
struct DerivedStruct : Base {}; // = : public Base

int main() {
    MyClass c;
    // c.x = 10; // ❌ Error: 'int MyClass::x' is private

    MyStruct s;
    s.y = 10;    // ✅ OK: Default public

    return 0;
}
```

### 总结 / Резюме

- 如果你想定义一个拥有复杂行为、需要封装的对象，使用 **`class`**。
- 如果你只是想定义一个简单的“数据包”（Plain Old Data），包含少量数据且没有复杂逻辑，使用 **`struct`**。
- **技术上**，它们的功能是完全一样的（`struct` 也可以有构造函数、虚函数等），只是默认开关的位置不同。
- Если вы хотите определить объект со сложным поведением и инкапсуляцией, используйте **`class`**.
- Если вам нужен простой «пакет данных» (Plain Old Data) с минимумом логики, используйте **`struct`**.
- **Технически** они идентичны (`struct` тоже может иметь конструкторы, виртуальные функции), отличаются только положения переключателей по умолчанию.
